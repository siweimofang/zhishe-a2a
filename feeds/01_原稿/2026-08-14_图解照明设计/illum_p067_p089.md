# 将间接照明、脚灯融入高低差、屋内木构造、家具（2·4·6）中的注意点

本页针对三个装设场景给出注意事项，各配示意图与条目说明：

**① 装到高低差内（利用高低差的间接照明）**
- 图示：阶梯式地面落差处设有黄色发光的凹槽间接照明。
- 图中标注：「100 mm以上」（开口高度）、「灯具宽度 + 50 mm 左右」。
- 说明文字：利用高低差来做间接照明，对老年人而言也很安全；开口处最低需确保100 mm以上。

**② 装到屋内木构造之中（木构造内的脚灯）**
- 图示：灯具埋入木造墙体/构造中，光线向下照射。
- 图中标注：「200~300 mm」（水平距离）、「100 mm左右」（垂直错位）。
- 说明文字：施工性好、成本较低，可作为边缘照明使用；必要时推荐使用外置电源的LED灯。

**③ 装到家具之中（家具内的照明）**
- 图示：柜体构造内的灯具，门扇附近。标注：「前方门」、「装上与前方门分开的挡板」、「空间死角」。
- 说明文字：要充分利用死角时建议采用外置电源；并注意避免灯具被门扇遮挡。

**逐项注意事项（条目）**

- **① 高低差的间接照明：**
  - 必须与建筑设计配合。
  - 开口处高度最低100 mm以上。
  - 10 W/m的LED即可获得足够的光通量，但多数LED需要外置电源，可能因此加大高低差。
  - 使用无眩光的日光灯，避免过亮。
  - 避免采用光泽地板，防止反射眩光。
- **② 木构造内的脚灯：**
  - 必须与建筑设计配合。
  - 灯具必须完全放入——木制品的尺寸必须大于灯具宽度（约100 mm）。
  - 推荐光源：10–15 W日光灯，或1–3 W LED灯。
- **③ 家具内的照明：**
  - 必须与建筑设计配合。
  - 应有助于家具的便利性（如收纳空间）。
  - 装设在死角的场合：必须保证维护与散热空间。
  - 装设在柜体/餐柜的场合：门扇开关时不得遮挡灯具。
  - 避免光泽表面，防止反射眩光。

# 形成影子或剪影的照明 (3) 的特征与注意点

- 与室内观叶植物搭配，在植物脚边装设小型投射灯。
- 调整光线方向，可在墙面上制造各种影子效果。
- 将灯具装设在植物后方照亮叶片，可强化剪影效果。
- 强调配光的方向性，避免光源直接暴露于视线中。
- 推荐光源：约10 W的卤素灯泡，或3–4 W的LED灯泡（E17灯头）。
- 注意：白炽灯泡发热量大，装在植物旁可能因热伤害植物，应避免使用。
- 可考虑简单装设方式，如将灯具吊挂在花盆内，效果更好。

# 如何选择放置型的地面灯 (5)

- 左图（Panasonic）：日式榻榻米房间，低矮木桌旁放着一盏方形发光的落地灯。图下文字：日本很早就习惯用落地灯照亮榻榻米，历史上常把照明器具直接放在地板上使用。
- 右图（KOIZUMI照明）：现代起居空间，红色椅子、玻璃栏杆，沙发旁一盏圆形暖光落地灯。图下文字：日本住宅的天花板普遍比西方低；把灯具放低有助于减少视觉压迫感，并引导视线自然向下。

条目要点：
- 避免过亮的落地灯侵入视线范围。
- 不用于照亮整个房间——光输出量应适中，借由光的扩散营造柔和感。
- 推荐亮度：约60 W等效（卤素或LED）。
- 家中有儿童或宠物时，避免直接接触玻璃/金属灯具。
- 装设时务必就近插入附近的插座使用。

右侧小示意图：三种灯具高度「低」「中」「高」，说明灯具高度变化对起居室空间感与纵深感的影响。

# 照亮墙壁，创造明亮空间

墙面是最适合融入照明的面。壁面照明能把光带入视线之中，即使地面附近照度较低，也能提升整体房间的明亮感，并影响整个房间的氛围。

- 左上照片：卧室床头上方的横向壁灯，标注「天花板灯与床头投影机一体化的样式」；图下标注品牌：大光电机。
- 左下照片：现代起居空间，多盏壁灯；图注：上下两方向出光的灯具样式。

  - 左图：向上与向下出光，标注高度「1」与「1」（合计为2个单位）。
  - 中图：仅向下出光，标注「1」与「3」（合计为4个单位），建议装设在约1/3高度处。
  - 右图：仅向上出光，标注「2.5」与「1」（合计为3.5个单位），建议装设在约1/2.5高度处。

装设提示条目：

- 视期望效果选择整体出光型或上/下出光型。

- 注意出光方向以及到天花板、墙壁的距离。

# 洗墙型筒灯的特征

- 无需装设在墙面上即可获得均匀的墙面照明。
- 适合照亮挂画、照片，营造画廊般的氛围。
- 完工后的天花板与地板颜色对比，可产生「浮动墙面」的效果。
- 可兼容的光源：日光灯、LED、日光色灯泡等。

**装设位置**
- 示意图：方形房间剖面，光源位于左上角附近，标注「D」（距墙距离）与「S」（灯具间距）。
- 条目：
  - 距墙距离（D）= 800–1000 mm
  - 间距（S）= 墙距的1–1.5倍
  - 色温因灯具种类而异；建议查阅产品目录的配光数据。
- 两张配光图：左图「单独装设」照度分布（等值线5、10、20、30 cd/m²）；右图「连续装设」同类型等值线，标注水平距离（0.18 m、1 m等）与垂直高度（0至4 m）。
- 图下说明：左图为60 W氙气灯泡洗墙型筒灯、距墙0.9 m装设的情况；右图为3盏灯具、间距1.35 m连续装设的情况。

# 窄光束筒灯的特征

- 主要用于较长的走廊。
- 连续设置光源可产生独特的展示效果。
- 可照亮墙面与地面的交界；走廊宽度≤3 m时，只需照亮一侧墙面即可确保足够亮度。
- 照片：走廊墙面上多道窄光束暖光投射效果。
- 图下说明：窄光束LED投射灯距墙约300 mm装设、间距约1000 mm，可减少灯具的存在感。

# 落地灯的特征

- 照亮墙壁最简单的方法。
- 可移动——插入不同插座即可随意改变照明位置。
- 左照片：卧室床边的高落地灯（大光电机），散发柔和环境光。
- 右照片：窗边（百叶窗旁）的落地灯，照亮墙壁与窗边区域。
- 小框「特征」：重复上述两条要点。

# 用面发光的照明来展示空间

面发光照明在住宅中并不常见，但可依客户要求在展示空间（墙面、天花板、地板等）使用。因款式多且性价比高，推荐使用LED照明。

**示意图（剖面，含编号标注）：**
- ① 前方面板（可见的发光表面）。
- ② 支撑构造/盖板——注明使用透明亚克力可更好地控制影子。
- ③ 光源（面板后方的LED灯）。
- 面板下方标注四段均等间隔，各标「1」（单位未注明）。

# 在发光面后方装设光源时的特征与注意点

- 发光面亮度高。
- 使用乳白亚克力或磨砂玻璃作扩散。
- 发光面到光源的距离与光源间距应保持1:1的比例（以获得均匀照明）。
- 此比例可能因光源种类、前方面板与背面空间而异；精确规划可能需要实物打样确认。
- 推荐光源：LED灯条（详细可参照第57页）。

# ① 前方面板的规格

- 最常用乳白磨砂玻璃或乳白亚克力。
- 狭长展示面宜用乳白亚克力。
- 面板过薄容易翘曲；最佳厚度约5 mm。
- 需要承重的场合须另行考虑结构。
- 亚克力易因静电吸附灰尘——避免在粉尘或脏污环境中装设。

# ② 内部规格

- 背面通常涂布哑光白色涂料，以确保出光均匀。

# 将照明融入家具之中

木质家具应在设计阶段就把照明考虑进去。好的照明设计能在不引人注意灯具本身的情况下提供足够的照明，并释放室内空间。把照明融入木质家具，可让灯具在视觉上「消失」，同时仍提供充足照明、腾出内部空间。

# 照明器具的收纳方式与注意点

两张标注示意图：
- 左图（垂直剖面）：灯具装在家具上方或下方。标注：
  - 「200 mm以上」（顶面上方净空）
  - 「高430 mm」（下部柜体高度）
  - 「让灯具不会被看到」
  - 「内部涂成白色」
  - 标签A（指向竖向净空）、标签B（指向灯具相对植物的位置）。
- 右图（墙面/家具交界）：壁装式灯具。标注：
  - 「灯具高度+50 mm以上」（表面上方）
  - 「灯具宽度+左右各30 mm」
  - 标签C、D（连接点与间隔）。

条目要点：
- 装设位置（家具上方/下方）与材质（天花板/地板反射率）的考量。
- 挡板高度建议约为灯具高度上方5 mm。
- 柜体后方的配置应避免造成阴影。
- 电视屏幕的照明范围约覆盖屏幕面积的一半，以减少眩光与眼睛疲劳。
- 以白色亚克力覆盖灯具时需开设散热通风孔（直径约15 mm）。
- 维护空间：LED或小型光源需预留约100 mm的检修余量。

# 用调光器来延长光源的寿命

调光器可调节亮度并降低耗电量，从而延长灯泡寿命。具体数据：
- 亮度降低10% → 省电10%，寿命延长为2倍。
- 亮度降低20% → 省电20%，寿命延长为4倍。
- 注意：单一回路不能无限制地并接调光器；必须遵守最大负荷容量。

# 白炽灯泡调光的特征与注意点

- 调暗后色温降低，光色变暖（偏红）。
- 调光器本体价格相对便宜。
- 配线只需电气配线即可（无需额外组件）。
- 支持0–100%连续无段调光。

# 卧室必须注意让人不舒服的亮光

卧室的整体照明应使用壁灯或落地灯营造柔和的间接光，避免床正上方天花板灯具的直射眩光。光源不得直接装设在床头板正上方，以免眼睛疲劳。枕边照明推荐使用无眩光灯具，装设在床垫上方600–750 mm处。若使用满铺筒灯或半直接型落地灯，应装在床侧而非床正上方。

# 卧室照明的三项基本要素

- 示意图：卧室平面，标注三个区域：
  - A（蓝色椭圆）：整体照明——通常为扩散型天花板灯或吊灯。
  - B（紫色椭圆）：枕边局部照明——如床头桌灯或壁装灯具。
  - C（大蓝色椭圆）：橱柜局部照明——开门时照亮衣柜内部。
- 条目说明：
  - A：以扩散型天花板灯或吊灯营造整体氛围。
  - B：以间接光或桌灯营造沉静氛围；推荐LED或日光色灯具。
  - C：天花板未装整体照明时使用；可装在衣柜内部或外部。
  - 另提及：床边可设脚灯，方便夜间起身。

# 橱柜装设照明的方法

**① 装在外面**
- 示意图：灯具装在衣柜外侧顶部边缘。标注：「依房间装修选择洗墙型投射灯或投射器等灯具——非常合适。」另注：「须确认光源是否影响门扇开关——若灯具位于门上方且与门开启轨迹重合，可能过热并有火灾风险——务必特别小心。」

**② 装在内部**

# 走廊要考虑到深夜的照明

工业标准中走廊需要30–75 lx，但实际所需亮度很低——主要目的是看清走廊尽头与照亮墙面，而非高环境光。推荐以5W的脚边照明搭配主灯（如夜灯）使用，避免影响睡眠。

# 设计照明时的注意点

三个标注框与示意图：
- 左框与图：壁装照明（筒灯或壁灯）。文字要点：
  - 光线应投向墙面，减少空间的封闭感。
  - 夜间照明应调暗；灯具间距约1800–2000 mm。
  - 图中标注水平距离「2500~3000 mm」（灯具到地面/尽端的距离），光锥投向墙面。
- 中框与图：人站在墙边，天花板装设灯具。文字要点：
  - 壁灯装设高度2200 mm；灯具最佳间距约2500 mm，以保证亮度均匀。
  - 光的扩散程度随灯具尺寸与光源瓦数而异，须依实际情况调整。
- 右框与图：卧室到浴室的动线地板照明。文字要点：
  - 建议装设脚边照明（距地面约300 mm），保证夜间安全行走。
  - 只照亮脚边区域、不照亮整片地板——避免过亮与影响睡眠。

# 走廊的照明案例

# 楼梯的照明必须注意垂直方向的安全

照明不足——尤其是光源造成明暗高对比时——会因纵深判断错误或阴影而导致绊倒危险。应避免光源直接暴露，灯具宜装在楼梯边缘而非正上方。

# 设计照明时的注意点

- 示意图：人上下楼梯，光源位于各处。标注框：
  - 左上框：避免「投射灯式」灯具——生硬的阴影会遮蔽台阶高差。
  - 左下框：光源不得被使用者直接看到（「不要让人直接看到光源」）。
  - 中下框：无论上楼或下楼，都应用台阶灯清楚标示第一级台阶。
  - 右侧框：避免使用照亮天花板上方的壁装灯具——这会使光源进入使用者视野，可能造成眩光或干扰。
  - 图中尺寸标注：距每级台阶边缘「300 mm」左右，灯具水平间距「2200 mm」左右。

# 楼梯照明的案例

- 照片：现代木楼梯，踏板下缘装设嵌入式或表面安装LED灯。
- 两处标注框：

  - 「无论上楼或下楼，光源都不会进入使用者的视野之中。」
