## 甲板式平台或露台的基础照明
1. 壁灯（屋檐下墙壁安装，向下照射）：
   - 注：虽然有灯具本身发光的壁灯，但有可能会给邻居带来麻烦，选择安装的灯具时要考虑周全
   - 注：壁灯的安装高度在2000mm左右，以便维修
2. 射灯（墙壁安装，照射树木/地面）：
   - 注：射灯安装的高度在2000mm左右，注意考虑维修方便
   - 注：射灯可以调整照射的角度，可以让灯光打到树木上，从室内观览夜景时比较漂亮。另外，安装带位移传感器、发出闪烁强光的类型还可以防盗

   - 注：在房檐下安装灯具时，可以选择防滴型筒灯，安装在想突出光线的位置或进出口附近较好……选用带位移传感器的灯具，不仅用来方便，还有防盗效果

## 连接室内外的光线

# 如何使用不同的室外灯具

照明灯具是电气产品，一般怕潮。用于潮湿场所的灯具必须具备防水功能，通常分为五类。部分制造商标注"IPxx"标记，可根据IP等级选择适合使用场所的灯具。

## 图解（左侧）
- 室外场景剖面图（建筑、地面、绿植），三种场所类型：
  - 防雨型：立杆上方，光束向下，用于露天淋雨场所
  - 防湿型：建筑内部靠墙，用于浴室、厨房等
  - 水中型：地面以下、水边，可长期浸没于水中使用
  - 另有标注：防雾型、防滴型

## 防雨型分类表（右侧）
| 类型 | 使用场所 |
|------|----------|
| 防雨型 | 可在户外淋雨环境下使用 |
| 防湿型 | 室内高湿场所（如浴室）使用 |
| 防滴型 | 屋檐下、室外——不可直接淋雨 |
| 防浸型 | 可承受一定程度的浸水——不可完全浸没 |
| 水中型 | 可水下使用；LED灯也可水陆两用（水中＋非水中） |

注：防湿型灯具仅限家庭使用，不能在商业高湿环境中长期使用。

## IP等级说明

# LED照明的应用

LED与传统灯泡不同，可进行完整的色温调节。LDK照明规划中，使用可调光调色、无眩光的LED灯具更有效。

LDK空间中如何区分使用调光调色型的LED照明灯具：区分使用光色和亮度，既可以制作美食，也可以享用美食。

## 做菜
- 图解：厨房/客厅空间，电视、沙发、盆栽、餐桌；人站在操作台前备餐；头顶射灯与吊灯发出白光（白色光锥）
- 说明：制作的时候采用白色光高照度，使人对味道更为阴暗【不清：原文"使人对味道更为阴暗"疑为"更能看清菜品色泽"之误，照录】。在餐桌上学的时候也是白色光更能让人集中精神

## 就餐
- 图解：两人坐在餐桌旁，暖黄色光笼罩，背景有电视与绿植；光源为吊灯与壁装灯具，黄色光束
- 说明：就餐时，暖色光线可以增加人的食欲，提高身体的消化能力。采用灯具本身发光的吊灯的话，可以增加照射绘画的灯具，感受餐厅般的愉快氛围

## 放松
- 图解：客厅场景，人坐在沙发上看电视，暖黄色光洒满空间，部分区域在阴影中；天花射灯、吊灯等，黄色调光束
- 说明：夜晚看电视等放松时段，将暖色光调暗，可以促进褪黑素的分泌，通过调光调色，也可以适用于白天看书

# 照明计划的思考方式与流程

（侧栏：照明设计）

照明效果因人而异，仅美观是不够的——必须从长期居住的角度设计舒适的照明（心理与生理影响）。照明亮度不仅取决于灯具本身，还取决于材质反射率与空间设计，因此照明规划需与室内设计在施工阶段紧密配合。各房间合适的亮度与氛围可参考本书p012～p016（第12～16页）。

## 照明计划流程（左侧流程图）
### ① 听取意见
- 确认业主的家庭成员构成、生活样式、喜好、要求等
- 现场信息调查

### ② 基础设计
- 把握建筑图纸
- 研究照明手法
- 选择照明灯具及考虑是否需要建筑化照明
- 计算主要房间的照度及检查亮度的平衡
- 制作照明配灯图及照明灯具清单
- 研究是否要分电回路、分别控制开关及调光
- 确认成本和电气容量

### ③ 施工设计
- 在展开图上调整灯具安装的位置高低
- 去灯具样板间或要来样品确认照明效果
- 确认吊灯需要的电线长度以及确定涂刷的颜色
- 决定照明灯具（订制品需要制作好图纸）
- 修改配灯图（平面图、展开图、立面图）
- 修改照明灯具清单
- 确认分电路、开关及调光的分别控制
- 最终确认成本和电气容量

### ④ 施工、监理
- 确认依照灯具规格图进行的施工方法
- 确认埋入灯盒等需要事先安装的灯具是否已经制作完毕
- 电线施工
- 照明灯具安装施工
- 对焦
- 确认调光平衡及设置照明情景

### ⑤ 竣工、交房
- 向房主说明调光方法和设置照明情景
- 向房主说明换灯泡的方法和照明使用方法
- 测量照度
- 拍摄照片

# 与房主针对房间亮度取得一致

（侧栏：4）

## 应向房主确认的要点
| 项目 | 内容 |
|------|------|
| 家庭成员 | 年龄、性别、性格等 |
| 职业 | 生活周期、是否双职工等 |
| 趣味、爱好 | 生活方式（是否想要家庭影院或酒吧，是否常在家举办派对等） |
| 对室内装潢的喜好 | 本国风格/西洋风格，传统风格/现代风格，休闲/正式 |
| 对氛围的喜好 | 重视开放感还是沉稳 |

| 对亮度的喜好 | 现在使用的灯具种类（含灯泡类型和瓦数）以及使用方便性 |

# 如何区别使用传感器与调光

（侧栏：照明设计）

## 传感器种类
- 内部型传感器（用于环境光/人感）：通常用于调光或自动开/关；外部型传感器（位置/移动）：可联动多盏灯具
- LED注意事项：按容量（而非体积）选择；部分LED灯泡内置传感器（如带人体感应的LED灯泡）
- 室内传感器可设在入口或高流量区域附近；室外或安防用途：离家时或夜间触发灯具

## 调光与省电、延长寿命之间的关系
调光不仅改变亮度，还能提高能效、延长灯具寿命。

### 左图：白炽灯泡调光时的特性
- X轴：电压变化[%]（0～110%）；Y轴：特性[%]（10～140%）
- 橙色实线"电流"：随电压平稳上升；红色虚线"寿命"：电压超过约90%后急剧下降
- 标注：调光越多电流负荷越小，越能延长寿命

### 右图：调光与亮度及省电之间的关系
- X轴：光束比[%]（0～100）；Y轴：消耗电力[%]（0～100）
- 绿色实线"白炽灯泡"：同亮度下耗电更高；蓝色虚线"荧光灯泡"：斜率更平，低亮度下效率更高
- 标注："80%的亮度可节省不到10%的能源"（白炽灯）；"80%的亮度可节省20%多的能源"（荧光灯）
- 下图注：荧光灯泡的光束比与消耗电力基本成正比，可以提高省电效果

## 底部文字
白炽灯经几个百分点的调光也可极高地延长灯泡寿命，仅增加调光开关就可避免寿命短的缺陷

# 施工检查

（侧栏：照明设计）

## 施工管理
- 照明安装施工期间的管理很重要，尤其是建筑化照明与壁装灯具
- 现场确认必不可少——特别是LED灯具（可能按批次生产、无库存）与翻新住宅（应带实物样品验证照明效果）

## 施工管理的内容
- ① 检查灯具及施工图：每两年核对一次产品目录；LED灯具每半年改款一次；传统灯具订购后约1个月到货，LED灯具多为批次生产，无库存时可能要等约一个月
- ② 施工情况的确认：建筑化照明（如整墙照明）要求精度高——接缝不平整在灯具点亮后会产生眩光，设计师必须现场巡视确认
- ③ 现场实验：实际安装受限时（如翻新住宅）进行实验——接通电源或用样品测试照明效果

## 各种灯具的检查要点
| 灯具种类 | 施工中的注意点 |
|----------|----------------|
| 筒灯 | 在图纸上标注安装高度与距墙距离；避免灯光直接照向墙壁（角度不当会降低有效照度）；有梁或木天花的房间避免在结构件上钻孔，寻找替代安装点 |
| 壁灯 | 安装前确认灯具类型（上/下出光）与匹配的灯具型号；安装高度与平面图一致；嵌入式壁装确保底座与墙面齐平 |
| 脚边灯或埋入地下灯具 | 混凝土结构需考虑配管与接线盒位置——多数接线盒在施工时安装；结构完工后安装时以安全为先，可能无法完全封闭安装 |
| 吊灯或枝形吊灯 | 通常直接安装在天花龙骨上——确保固定到承重结构；检查重量限制——过重可能造成位移或损坏；确认照明方案时同时核对其他电气设备位置 |
| 射灯 | 安装带防护罩以防积尘；荧光射灯单元间距要避免过热积聚——尤其夏季花园等露天环境通风至关重要 |

# LED灯的维修注意点

（侧栏：4 照明计划制定流程与产品选型DIALUX）

## 正文（左栏）
- LED在节能方面发挥重要作用；即使LED不一定总能提供充足照度，其设计仍可利用固有长寿命
- 纠正误解：LED寿命长≠无需更换——仍需定期检查
- 参照原书第22页：即使LED寿命长，清洁/检查也应至少每年一次

## 光束维持率比较数据（图表）
- Y轴：光束[%]（约70～100）；X轴：时间(h)（0、3000、5000、10000、20000、30000、40000、50000）
- 四条曲线：
  - 红色"LED"：起始100%，约40000h前保持近100%，约50000h后急剧下降
  - 黑色上曲线"100V带二色向反射镜卤素灯泡"：约3000h后快速下降，5000h时约85%
  - 黑色下曲线"小型荧光灯泡"：下降比卤素灯更陡，10000h时约80%
  - 最低黑色曲线"陶瓷金卤灯"：下降最快，10000h前已低于70%
- 注：灯泡型LED灯与LED模块的情况不同，不同厂家生产的产品也有可能不同

## 右侧文字块
- 引用2010年修订的JIL5006（日本照明器具标准）：LED灯具寿命定义为光输出降至初始值70%的时间——即累计运行时间达到光输出70%的时间点
- 该定义适用于通用照明用白光LED模块

# 照明用语集（1）——主要术语定义

## 术语定义
- 1/2照度角：灯具垂直向下照度降至峰值一半的角度；用于计算灯具间距以获得均匀照明
- 1/2光束角：光强曲线右侧最大光束宽度对应的角度；光束角越小光线越聚焦
- IP：IEC标准等级——第一位数字＝防尘（如6＝完全无侵入），第二位数字＝防水（如8＝可连续浸没）
- 亮度感觉：受环境照明与材质反射率影响的主观视觉亮度——厂商不提供标准化数据
- 色温：光色随温度变化（高K偏白→蓝，低K偏红/橙）；单位开尔文（K）
- 能量消耗率：评价LED灯具能效的指标
- 显色、显色性：两种体系——平均显色指数（Ra）与特殊显色指数（如R9红色）
- 扩散光：从表面或光源向多方向散射的光
- 间接照明：经天花板/墙面反射而非直接照射的照明
- 灯具效率：灯具出光量占总发光量的比值
- 辉度：单位面积发射或反射的光量；单位cd/m²

## 左栏术语

# 照明用语集（4）——术语定义（续）

## 顶部段落（部分截断）
时需要使用维修率（修补系数）进行计算……（确保使用一段时间后的照度水平）。→参照第22页

## 多重阴影
指多个阴影重叠的情况，从发光部位到阴影之间的对称距离如果是发光部位的10倍以上，不会产生多重阴影，但多核LED的桌灯则很容易产生多重阴影。→参照第91页

## 明暗适应
- 暗适应：从亮的地方进入暗的地方时，即使开始什么也看不见，经过一段时间后眼睛可逐渐适应
- 明适应：从暗的地方突然进入亮的地方时，即使开始感到很刺眼，经过一段时间后眼睛可逐渐适应
→参照第10页

## 明度对比
由于周围颜色明度差异，同一种颜色看上去却不同的现象。→参照第11页
