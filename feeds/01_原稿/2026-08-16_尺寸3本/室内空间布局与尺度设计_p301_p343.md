### 印页296（非住宅设计）（PDF p306）

**标题：零售空间：剖析与问题**

【本页为三栏文字+右侧「鞋店透视图」插图】

**正文（五段）：**
- 零售空间设计是一种引人入胜的室内设计类型，需要将产品、空间、图形与标识结合起来，以促进销售。
- 商店设计的作用在于提升产品的呈现效果、效率与顾客的舒适度。
- 典型的商店为矩形，长边由前至后，短边朝向店面；空间划分为展示区、服务区与流通区，强调开放、透明的环境以引导人流；靠近入口处的展示可获得最大效果。
- 产品分为主要商品、配件与冲动型商品（如收银台附近的配件），按类别分组摆放，高利润商品置于显眼位置（如靠近收银台），以达到视觉和谐并引导顾客动线。

**右图（鞋店透视图）：**
- 图注：鞋店透视图
- 图为黑白线描透视：前景低矮木质展示桌，多双鞋整齐摆放（部分在支架上）；中景服务柜台带电脑显示器；背景为网格背板货架存放商品；天花板有照明/通风设施，最右侧可见椅子

### 印页300（非住宅设计）（PDF p310）

**标题：零售空间：交通动线**

**顶部正文（两栏）：**
- 交通动线应直观、轻松且不使人疲劳；平滑简单的路线可减少顾客的脑力负担，使注意力集中在产品上。
- 路径应遵循战略性的、合乎逻辑的顺序（如结合视觉销售策略），避免过于僵化或过于开放的布局导致拥堵或混乱。
- 在繁忙的商店中，多数顾客并不会直线穿过，而是在关键点之间来回折返；应设计流动导向的路径（而非僵硬的直线路径），以允许自然移动、共用通道，并在紧急情况下快速到达出口——同时仍要避免过于开放的布局。

**四幅示意图（从左至右）：**

1. **线型**
   - 图：矩形店内竖向中央通道，两侧有分支箭头
   - 说明：适合狭窄的商店；路线可以完全连续，或环绕中央岛型展示；强调简洁与高效。

2. **环形**
   - 图：U形/环形回路，带进出箭头
   - 说明：适用于设有中央展示区或墙面展示的商店；可同时到达中央与周边区域。

3. **节点式**
   - 图：分支路径带圆形节点，箭头多方向
   - 说明：常与线型或环形结合；强调活动发生的位置——如展示或活动扩展区。

4. **有机的线型**
   - 图：不规则迷宫状曲线路径，呈U形或S形带内环
   - 说明：当展示架与展位非对称放置时使用，形成灵活、多方向的流动；比纯线型或环形更自由。

- 说明：虽然总体动线仍是前到后，但并不直接——因内部展示与墙体元素的制约而成角度（约45°转角）。

**左页图2（有机的自由形）：**
- 图注：有机的自由形
- 图：流体曲线动线，多回路与分支，箭头多方向穿过散布的展示单元
- 说明：非对称、非线性布局，依据墙体与展示位置形成有机、灵活的流通。

- Exit doors / 逃生门：能够通向出口的门，例如通向防火走廊、防火楼梯或通向室外。

【本页为词汇表 N–W 部分，页脚标注「词汇表 329」】

**N**
- Needs / 需求：在设计过程中，需求是项目中不可改变的、具体的要求。
- Noise / 噪声：不受欢迎的声音；通常（但并非总是）非常响亮。
- Number of exits / 出口数量：法律规定的空间或楼层中最少出口数量，主要基于场地规模与用途类型。

**P**
- Parti diagram / 场地分析图：极简的抽象图，用于抓住方案的基本组织模式。
- Personal space / 个人空间：身体周围的空间；未经许可不允许非物理性进入——否则视为入侵。
- Perspective drawing / 透视图：环境或物体的图像化三维表示。
- Physical factors / 物理因素：人类与环境物理性质之间的关系。
- Physiological factors / 生理因素：人体生理状况及其与外部环境的关系。
- Practicality / 实用性：通过设计产生的品质，结合了功能性、易用性与舒适性。
- Privacy / 隐私：控制环境条件的能力，包括视觉与听觉暴露。
- Private office / 私人办公室：封闭房间内的办公空间。
- Programming（参见 brief）/ 计划书：描述项目目标与要求的文件。
- Properties / 特性：具体、可见的特点设计特色，例如，垂直的、曲线的或者通高的。
- Prospect / 视野：提前计划好的、未来可以见到的一种景象或场面，通常用于吸引人们朝着此方向前进。
- Proxemics / 人际距离：研究人们交流时彼此之间距离的科学。
- Psychological factors / 心理因素：这些因素包括人类与行为模式及社会需求的相关方面。

**R**
- Relationship diagrams / 关系图解：表现项目中不同部分之间关系的示意图。
- Room adjacencies / 空间相邻：在功能上需要邻近的房间，根据房间位置、隔墙类型、通行入口决定如何邻接。

**S**
- Scales / 比例：指的是空间内部建筑和其他非固定元素的相关尺寸，尺度范围包括从大到小的所有要素。
