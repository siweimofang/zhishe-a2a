# 壁纸

塑料壁纸的性价比高，极为普及。布壁纸给人以高级感和厚重感，多用在酒店等地。

**塑料壁纸**

以聚氯乙烯树脂（PVC）、布或薄膜等为原料，多用于墙壁和天花板。优点：施工容易、品质稳定、成本低；缺点：透气性差，若维护不当容易发霉。住宅、办公室、酒店等普遍使用。

【图：「塑料壁纸的结构」示意图，自表及里标注：印刷、聚氯乙烯树脂、热压接、棱棉纸【「棱棉纸」疑为「楞棉纸」之误，原文如此，逐字【不清】】。】

**布壁纸**

具有高级感，耐久、防潮，但价格较高、清洁困难。常用羊毛、丝绸等纤细纤维制成，也含有植物纤维。可与无纺布底衬等其他材料复合，构造方法多样。

【图：「布壁纸的构造」示意图，标注：编织物、纤维、粘着剂层、棱棉纸【「棱棉纸」同前，逐字【不清】】。】

**纸质壁纸**

以纸浆制成，触感柔软温和。环保、透气，适合注重健康的使用者；但易受污染、怕潮湿。

【图：「纸质壁纸的结构」示意图，标注：棱纸、和纸、楠麻纸、月桃纸、粘着剂层、棱棉纸【「楠麻纸」「月桃纸」等名称逐字【不清】】。】

# 榻榻米与植物纤维质地地板

榻榻米的吸湿性和散湿性很好，非常适合气候湿润的日本。除了使用自然材质的传统榻榻米以外，还有使用合成纤维的建筑材料榻榻米。

**榻榻米**

以蔺草（灯心草类）编织席面、内芯以稻草等构成的「地板」制品。弹性好，具有保温、隔音性能；主要使用草席、纸、木材等环保材质。吸湿、散湿能力强，适合日本潮湿气候。标准尺寸为1:2的长宽比（长边与两倍短边），也有正方形（半叠）或长方形规格。近来出现无边榻榻米——更耐用、适合人流量大的场所，但需定期对表面进行维护。另有以合成纤维、压缩成型制成的「建筑材料榻榻米」（化学榻榻米）。

【图：「榻榻米的构成」剖面示意图，标注：榻榻米边（材料：藤、竹、花等）、榻榻米面（蔺草编织席面）、榻榻米底层（稻草、竹、压缩纤维板等层叠材料）。分层按等级划分，共分4个等级（原文为概述转述，逐字文字【不清】）。】

**植物纤维材质地板**

以竹、藤、棕榈、椰子等植物纤维制成的地板材料，作为传统榻榻米的替代。厚度300–500mm【疑为「3–5mm」或「30–50mm」之误，原文如此，逐字【不清】】。多为预制地板块，施工方便，适合步行（尤适用于大型设施）。

（2）建筑材料榻榻米（剖面多层，自表及里）：表层、上配、棒手配、加强材料、竹纤维板（聚苯乙烯泡沫板【该标签逐字【不清】，疑有误读】）、下配、里材；注：含稻草。】

# 布与地毯

纤维分为天然纤维与化学纤维，各有优缺点。地毯种类繁多，铺设方法也多种多样。

**照片1 代表性的布匹种类（样块6件）**

1. 纺织物：经纬交错的厚实纺织的「平织」法
2. 编织物：横向或纵向连续钩针编织的「钩织上树」法【「钩织上树」疑为误读，逐字【不清】】
3. 蕾丝：把毛线搓线，组合，形成透明的网状
4. 毛毡：在纤维里加入水，通过热、压力，压缩成布状
5. 无纺布：用粘贴剂等将纤维固定，起毛后就成了「羊毛」【「羊毛」疑为「毛毡」之误，逐字【不清】】
6. 粗颗粒：纱布等网格状编织物给人一种粗糙的感觉【「粗颗粒」疑为「粗布」类名称误读，逐字【不清】】

**地毯的铺设方式**

- 全铺：整个地板都铺满。
- 中铺：铺设面积比房间的面积要小，可以露出地板，显出两者的对比效果。
- 片铺：铺在桌子下面或床旁边，局部铺设。
- 叠铺：在全铺的基础上再局部铺设的方法，用来展现不同的颜色和纹样。

# 窗帘（窗饰1）

窗帘头的褶子很大程度上决定整体印象，窗帘导轨（窗帘杆）在室内设计中也是重要的存在。

**窗帘的种类和褶子**

窗帘是用以遮光或装饰的功能性布制品。褶子指窗帘上部（窗帘头），具有美化外观的作用，可简可繁。当前流行的趋势为无褶平幕窗帘。

**窗帘头的设计**

窗帘导轨（窗帘杆）同样是室内设计中的重要元素。
