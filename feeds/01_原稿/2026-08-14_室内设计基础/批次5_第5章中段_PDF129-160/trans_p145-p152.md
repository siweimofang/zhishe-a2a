（原文为概述转述，逐字文字【不清】）小而整洁的空间有利于保持卫生，住宅与商业设施（商店、公寓等）皆然；即便是高档店铺也可能采用简洁的设计，但仍须重视隔音与防臭处理。

## PDF页码 150（印刷页：154）

### 体效效果的色彩计划【不清：主标题用字存疑，按图读取结果为「体效效果的色彩计划」】

导语段：同样的颜色在不同人的眼里是不同的模样，也会给人不一样的感受。在进行色彩设计的时候，要充分关注这种心理感受所要求的效果以及对颜色之间的配搭。

左栏（原文为概述转述，逐字文字【不清】）：色彩给人带来不同的心理暗示，红、绿、蓝等颜色会影响人的知觉与情绪。

正文要点（原文为概述转述，逐字文字【不清】）：涉及色相对比、亮度对比、彩度对比、色彩调和、色彩同化等概念；举例包括：医疗环境中红与绿的运用、浅色背景上深绿色形成的高对比、暖色（红、橙）感觉厚重而亲切、冷色（蓝、绿）感觉轻快而冷静。

**右栏术语定义**

- 心理补色：色觉系统诱发出了相反色相红—绿、黄—蓝。
- 色相对比：目标物的颜色会在背景色的影响下变得不同的现象。
- 亮度对比：目标物的颜色会在背景色的影响下变得清晰或模糊的现象。
- 彩度对比：目标物的颜色会在背景色的影响下变得更加鲜艳或暗沉的现象。
- 色彩对比：目标物的颜色接近背景色的现象，当背景色是网状物时，效果更明显。【不清：此条与「色彩同化」定义疑似重复或错置】
- 色彩同化：目标物的颜色接近背景色的现象，当背景色是网状物时，效果更明显。【不清：此条与「色彩对比」定义疑似重复或错置】

**色彩设计的顺序（5步流程图）**

1. 掌握情况：了解空间构成要素（地板、墙壁、天花板、家具等）的材质、形态、尺寸等。有些产品存在颜色的限制。
2. 初步构想：根据空间的使用目的、客户的要求制定出初步构想。
3. 确定方案：明确基调色、搭配色、强调色间的分配比例。配色最重要的是“统一和变化”的协调。
4. 方案展示：将想法做成方案，还要模拟出完工后的上色透视图或效果图；尽量保留一些大号色板和样板。
5. 着手施工：施工队按照设计师的设计开始动工。设计师在现场进行详细指示和相关确认工作也是非重要的。【不清：末句「也是非重要的」原文存疑】

### 照明计划1

### 照明的基础知识

**灯光照明以及光线的作用**

（原文为概述转述，逐字文字【不清】）照明有两类作用：一是「照明」（提供整体亮度），二是「烘托」（营造氛围）；阴影对空间的纵深感和视觉趣味必不可少。照明还可通过褪黑素调节影响人的睡眠节律。

**从一室一灯到组合照明**

（原文为概述转述，逐字文字【不清】）多数住宅使用多个灯具以实现均衡照明，尤其在大空间或复杂空间中；单一灯具可能造成照度不均，建议采用多灯具组合照明。

**照明设计要符合空间使用目的**

（原文为概述转述，逐字文字【不清】）高档餐厅需要明亮、均匀的光；酒店大堂需要温馨、迎宾的光；走廊等安全关键场所宜设地面照明或踏步照明；不适宜安装顶灯之处，可使用落地灯或壁灯。

**地脚灯**（右侧注记，蓝点标记）

（原文为概述转述，逐字文字【不清】）用于走廊、楼梯及多区域安装，主要作用是引导动线、增强空间识别性；光线应集中向下照射，以有效照亮行进路径。

**照明术语表**

| 术语 | 定义 |
|---|---|
| 光束（lm） | 光源（电灯）发出的光线的集合 |
| 光度（cd） | 光线的强度 |
| 照度（lx） | 每单位面积所接收到的光的量 |
| 亮度（cd/m²） | 从某个角度看到的光线的强度、亮度 |
| 色温（K） | 表示光线颜色的单位。越红数值越小，越蓝数值越大 |
| 显色指数（Ra） | 表示光源对物体的显色能力的指数。Ra100能再现物体颜色 |
| 酷光【不清：原文用字存疑，疑为「眩光」】 | 亮度过高会导致眼疲劳，让人感到不适 |
| 反射率 | 根据室内用材的材质、颜色而变。用于计算亮度 |
| 安定器 | 用于点亮放电灯。电子化的叫做变频器 |
