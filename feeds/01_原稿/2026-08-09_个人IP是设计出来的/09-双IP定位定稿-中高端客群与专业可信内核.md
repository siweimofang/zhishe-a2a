# 双IP定位定稿（修订版）：一个出口、一个入口、内核一致

> 定稿依据（2026-08-06，两次收敛）：
> 第一次：两个IP的客户群体都是中端以上装修业主，最好是中高端人群（体制内公务员、事业编、企事业单位中层以上管理者、商人、教师、医生、律师等）。他们关注：设计师能力水平、审美高度、对生活的理解、经验、交付能力、信任感、品质生活追求、高颜值。
> 第二次修订：中高端业主客群定位成立，但归设计师IP使用；你的IP不适用该客群人设——你不做微观的单兵作战，发展方向是宏观战略：靠AI技术卡位、帮助B端获客、用AI赋能B端设计师。你的IP客群回归装修从业者（B端），AI是内容主角（这是你的核心优势，不是配角）。
> 内核不变（双IP共用）：**通过状态、气质、风格、品质，传递一件事：我既专业又值得信任。**
> 本文件为双IP定位总纲，以此修订版为准（覆盖初版09文档及05文档相关草案）。

## 一、为什么这个定位成立

**设计师IP（出口，C端）**：中高端业主不缺装修资源，缺的是"可信的判断"。他们见过足够多的推销，市场上"看起来很专业"的装修内容很多，但能同时做到专业、真实、克制的极少。他们信任"从容的专业感"——不讨好、不催促、有底气。

**你的IP（入口，B端）**：装修行业不缺装修人，缺的是"能带他们拿到新流量、新工具、新打法的人"。AI技术卡位——讲装修的人不懂AI，讲AI的人不懂装修，交叉点是空白赛道。你的独立立场天然可信：**你不做装修生意、不跟从业者抢客户，你只给他们武器。** 从业者不怕工具商，怕的是同行和骗局——这就是你的信任状。

两个IP的内核验证（书里的话）：价值来自共鸣，不只是内容质量（"垂直是对粉丝垂直，而不是对领域垂直"）。设计师IP垂直到中高端业主的关切（审美、品质、交付、信任）；你的IP垂直到从业者的关切（获客、效率、AI落地、行业方向）——两个池子都小，但都精准，都是"低粉高客"的路子。

## 二、客群画像卡（双客群）

### 设计师IP客群：中高端装修业主

**人群构成**

体制内公务员、事业编、企事业单位中层以上管理者、商人、教师、医生、律师，以及收入与审美品位同档的自由职业者、个体经营者。城市以一二线及强三线为主，年龄段集中在30-55岁，多数是改善型需求（置换、大平层、别墅、学区房升级），家庭决策中双方共同参与，女性在审美决策上话语权重。

**决策特征（与普通客群的关键差异）**

- 决策周期长、比较充分：会同时看多个设计师，考察期以月计，不轻易被促销打动
- 信息来源多元：小红书、抖音、朋友圈之外，还会问朋友、问同事、看工地实景
- 价格敏感度低，价值敏感度高：愿意为"确定性"付费，但怕被当冤大头
- 契约意识强：重视书面流程、节点验收、售后承诺
- 识破套路能力强：夸张话术、虚假案例、前后矛盾，一眼看穿且会传播

**关注点（内容方向）**

| 关注点 | 它实际在问什么 | 内容怎么回应 |
|---|---|---|
| 能力水平 | 你真有本事吗 | 方案背后的设计逻辑，不只展示效果图 |
| 审美高度 | 你懂我想要的品质感吗 | 风格解析、材质搭配、细节处理（克制高级，不堆砌） |
| 对生活的理解 | 你懂我的生活方式吗 | 从生活场景出发讲设计（孩子、宠物、收藏、会客） |
| 经验 | 你踩过多少坑 | 真实项目复盘、施工节点的专业判断 |
| 交付能力 | 你说到能做到吗 | 工期、验收、落地过程记录（不是效果图，是实景） |
| 信任感 | 你会不会坑我 | 报价透明逻辑、避坑实话、不回避问题 |
| 品质生活追求 | 我们是不是一类人 | 生活方式内容：质感、留白、细节之美 |
| 高颜值 | 看着舒服吗 | 账号本身的审美即第一张名片（视觉克制、统一、精致） |

**深层需求**：要的不是"装修"，是"确定的人生秩序"——一个按他们生活方式长出来的家；不是"便宜"，是"值得"；不是"服务"，是"尊重"；不是"热闹"，是"体面"。

**内容触点**：小红书（搜索决策主力，看案例看评价）→ 抖音（刷到认知，看人看态度）→ 微信私域（深度沟通，看细节看为人）→ 线下（见面、看工地、看交付）。

### 你的IP客群：装修从业者（B端）

**人群构成**

独立设计师、装企老板与中层管理、家装从业者（业务、工长、转型者）、想入行的新人。他们有共同的处境：市场下行期获客变难，AI浪潮正在改写行业规则，但大部分人既没工具也没方法。

**决策特征**

- 为订单焦虑：一切内容的价值判断标准是"能不能帮我获客/提升单值"
- 对AI既期待又怀疑：怕错过，更怕被割韭菜（见过太多AI培训收割）
- 懂行：专业内容水不水，一眼看穿——干货阈值比业主高得多
- 时间碎片化：工作日忙工地、忙谈单，学习时间集中在晚上和碎片时段
- 付费谨慎但果断：确认有用后，愿意为"直接换订单"的工具和方法付钱

**关注点（内容方向）**

| 关注点 | 它实际在问什么 | 内容怎么回应 |
|---|---|---|
| 获客 | 我的客户从哪来 | AI获客实操：内容、谈单、转化的真实案例与数据 |
| 效率 | 我能不能少干点杂活 | AI工具在量房、纪要、报价、方案上的实测 |
| AI怎么落地 | 工具这么多，哪个真有用 | 知设等工具的真实使用过程（行家实测，不是广告） |
| 行业趋势 | 这行未来往哪走 | 宏观洞察：AI时代的获客格局、设计服务升级 |
| 同行案例 | 别人怎么用AI赚钱了 | 帮设计师做IP的实操复盘（真实过程，脱敏） |
| 转型焦虑 | 我会不会被淘汰 | 把焦虑翻译成路径：先学什么、再做什么 |

**深层需求**：订单焦虑（获客难）、转型焦虑（怕掉队）、信息差焦虑（"别人在用的工具我不知道"）。你的内容要"安抚焦虑+给工具+给路径"——这三件事都做，才叫指路人。

**内容触点**：小红书（从业者聚集，搜"设计师获客""AI装修"）→ 抖音（泛流量认知）→ 微信社群与私域（深度连接、课程与服务成交）→ 线下活动（训练营、分享会，从线上信任走到线下关系）。信任顺序：先看技术真实性（你是不是真懂）→ 再看实战成果（数据、案例）→ 再看方法论（能不能复制）→ 最后付费。

## 三、信任传递体系：把"专业可信"落到三层

内核不是一句口号，要靠三层持续传递。两个IP共用这套体系，表达对象不同。

**状态层（第一眼的直觉）**

账号的一切视觉都在说话：头像、封面、色调、排版、出镜形象。

- 设计师IP：审美是第一张名片——克制、留白、低饱和高级感，与业主客群的审美同频
- 你的IP：技术可信度是第一张名片——真实工作场景（办公室、工具界面、数据截图）、整洁利落、说人话
- 共用原则：头像真人实拍（不用AI生成图，你已定论）、全平台同一套视觉、无论哪个平台都"看着像同一个人"

**内容层（持续输出的证明）**

- 设计师IP：讲清楚"为什么"（设计逻辑）、提供高于平均的美学判断、有成绩说成绩有局限说局限、不催单不制造焦虑
- 你的IP：实测是真的实测（行家面前水不了）、数据是真的数据（不夸大不编造是你的铁律）、方法论能复制（从业者拿去能用）、敢说真话（工具该不该用、什么场景没用，都直说）
- 共用原则：真诚、克制、不夸大——这个客群（业主和从业者都是）最擅长识破

**行为层（互动与服务中的细节）**

- 评论区认真回复每个专业问题，答不上来诚实说"这个我需要核实"
- 私域不群发轰炸，按需沟通，尊重节奏
- 做错了正面认，改给你看——敢认错的人最服人
- 服务与交付流程讲清楚，用确定性换信任

**一条铁律：降营销感，升专业感。** 同样的内容，用"分享判断"的方式说，而不是"推销服务"的方式说。双IP共用。

## 四、双IP分工矩阵：一个出口、一个入口（修订版）

核心分工不变：**设计师IP是"可被选择的对象"（成交出口），你的IP是"可信赖的行业指路人"（入口）**。变化的是：出口面向业主，入口面向从业者——你的入口直接通向MCN的签约池，不再绕道业主。

| 维度 | 设计师IP（出口） | 你的IP（入口） |
|---|---|---|
| 客群 | 中高端装修业主（C端） | 装修从业者（B端：设计师、装企、从业者） |
| 角色 | 被选择的设计师 | 行业的AI指路人 |
| 立场 | "我交付你想要的家" | "我不做装修生意、不跟你抢单，只帮你用AI变强" |
| 内容重心 | 实景案例、设计理念、交付过程 | AI赋能装修实战、B端获客方法论、行业洞察 |
| AI的地位 | 后台工具（不喧宾夺主） | 主角（核心优势，技术卡位） |
| 信任锚 | 作品 + 交付实景 | 技术真实性 + 实战成果 + 敢说真话的独立立场 |
| 变现方式 | 设计签约、装修订单 | 知设工具、培训课程、深度咨询、MCN签约池 |
| 性格风格 | 设计师本人的气质 | 你的气质：实战、克制、说人话 |
| 相互关系 | 你的IP为它提供方法论（内容与获客打法） | 设计师IP的实操成果反哺你的IP案例库与公信力 |

**你的IP立场详解（重要）**

"我不做装修"这句话，对从业者说是信任状，对业主说是空话——这是初版定稿定位跑偏的根源，本次修正回来。

- 面向从业者："我不做装修，我做的工具和方法，都是给你拿订单用的。我不跟你抢客户，所以我们之间没有利益冲突，我的话你可以信。"
- 面向从业者的"指路人"翻译：不是指路业主怎么选装修，而是**指路从业者看清AI时代装修行业往哪走、怎么用AI获客、怎么升级自己的服务**
- AI是主角：实测、数据、方法、案例——你输出的一切都围绕"AI技术卡位"，这是你的优势，不隐藏、不降格
- 宏观不是空谈：战略感用"打法的规模"证明（一套方法论赋能很多设计师），不用"情怀"证明

**内容禁区（双IP通用）**

- 不做纯AI生成内容（撞AI标识合规红线，也违真实人设）
- 不评价同行、不贬低竞品（包括同类AI工具——你的位置是"行家实测"，不是"友商黑稿"）
- 不晒客户隐私（案例一律脱敏，客户照片需授权）
- 不搞"最后三天"式促销话术
- 不贩卖焦虑（对业主："90%的装修都被坑"式开场是自杀；对从业者："不用AI就被淘汰"式恐吓同样无效——他们天天听，免疫且反感，要用"机会"叙事代替"威胁"叙事）

## 五、与书中方法论的一致性验证

**低粉高客模型**（"垂直是对粉丝垂直，而不是对领域垂直"）：两个IP都是小池子高价值——设计师IP垂直到中高端业主（客单高、决策重）；你的IP垂直到从业者（池子比业主更小，但单客价值更高：工具、课程、服务费、MCN签约）。都无需百万粉，需要精准触达和高转化。

**四相信任模型**（相识→相知→相信→相依）：两个客群信任周期都长。设计师IP侧业主观察期以月计；你的IP侧从业者观察更"尖"——他们会扒你的实操数据、验证你的工具。四相都走扎实：相识（审美/专业第一眼过关）→ 相知（连续输出3个月以上）→ 相信（真实案例、实测数据、敢认错）→ 相依（私域长期维护，装企和设计师是长期客户，不是一锤子买卖）。

**意见领袖四要素**（品格/知识/情感/技能）：
- 品格：不夸大、不编造、独立立场——对从业者展示为"行家说真话"，对业主展示为"不坑人"
- 知识：设计师IP=设计深度与审美高度；你的IP=行业深度+AI深度（你的532条实战经验库+知设实操）
- 情感：设计师IP懂业主的生活方式；你的IP懂从业者的订单焦虑
- 技能：设计师IP=交付能力（作品说话）；你的IP=工具落地能力（产品与案例说话）

**失败六因自查**：两个客群对"纯营销"和"贩卖鸡汤"的容忍度都接近零，红线中的红线。"没聚焦"尤其要防：你的IP不能又讲AI又讲装修知识又讲人生感悟——一切内容回到"AI×装修"一个交叉点。B端客群的"不坚持"代价同样大：从业者观察期长，断更他们不会催你，只会悄悄失去你。

## 六、对MCN体系的意义（修订版）

初版定稿里你的IP是"业主的指路人"，为设计师IP导流——绕了远路。修正后闭环更直接：

**你的IP吸引从业者 → 从业者亲眼看着你帮设计师IP做获客（过程本身就是内容）→ 设计师、装企带着信任来签约MCN → 用同一套方法复制下一个设计师。**

对照书里托育星球的三支柱：

| 托育星球（书中） | 你的对应（修正后） |
|---|---|
| 流量建设 | 你的IP（行业号，从业者流量）+ 设计师IP（案例号，业主流量）双线并行 |
| 线下活动 | AI训练营、设计师分享会、装企内训（从业者流量线天然承接） |
| 品牌IP打造 | 为设计师提供IP代运营/获客服务（MCN第一阶段业务） |

定位定稿 = MCN的选人标准与包装模板：内核（专业可信）可复制，风格（随人）可差异。你的IP是这套模板的第一个完整案例——当你用这套方法把自己的IP做成"AI指路人"，再复制给设计师时，就是活广告。

## 七、调整说明与风险提醒

**调整说明**：初版09文档中"你的IP面向中高端业主、AI降为背书"的定位不适用，本次撤销。你的IP回归B端从业者客群（与05文档原方向一致），并升级三点：立场明确（不抢单的工具商）、角色明确（行业的AI指路人）、AI重新做回主角。设计师IP维持中高端业主定位不变。其余框架（信任三层、内核、铁律）不变。

**风险提醒**：

1. **B端客群更懂行**：从业者会验证你的每个实测、每张数据——内容必须真材实料，含糊一次就失信。好在这是你的主场：知设就是你的活案例
2. **转化周期同样不短**：从业者观望者多，付费前要确认"你懂我、工具真有用"。前期目标依然是"方法论资产积累"而非成交数据
3. **工具商立场是资产也是约束**：你不能因为想签设计师就夸大工具效果；对知设的演示要区分"已上线功能"与"开发中能力"，这是行家观众最在意的边界
4. **双IP内容区分度要刻意维护**：你的IP讲"怎么获客"，设计师IP讲"怎么交付"——分工天然清晰，但要在选题表上刻意维护，避免互相稀释
5. **别让两个客群互串**：你的IP粉丝（从业者）不是设计师IP的客户；设计师IP粉丝（业主）也不关心AI获客。互推要克制，各线内容保持纯净，避免从业者噪音影响业主对设计师IP的信任
