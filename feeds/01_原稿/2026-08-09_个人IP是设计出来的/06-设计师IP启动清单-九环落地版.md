# 设计师IP启动清单（九环框架落地版）

> 依据：《个人IP打造方法论精华》（04文档）的九环框架 + 《设计师个人IP打造框架》（01文档）
> 用法：按周执行，每项标注对应九环；"待详情"项等你提供设计师个人详情后填充。
> 预期：第1-3周完成启动，第4周起进入稳定内容期。

---

## 第1周：基建周（环1定位 + 环2人设 + 环6流量）

### 本周目标
账号四件套定稿、主页装修完成、素材库骨架建好、对标研究启动。

### 任务清单

**1.1 补齐详情（环1，待详情）**
- [ ] 设计师八项详情收集完成（见01文档第六节：称呼城市/年限背景/擅长类型/案例数/出镜意愿/每周时间/团队支持/流量预期）
- [ ] 实景案例素材盘点：可公开案例照片（至少30张高清原图）、改造前后对比图
- [ ] 资质材料：证书、奖项、媒体报道（如有）

**1.2 一句话人设定稿（环1）**
- [ ] 用公式"城市+年限+专精领域+可量化成绩"写出初稿（3版）
- [ ] 与设计师本人确认：标签选哪个派系（风格/功能/透明/全托管/旧改），主标签+副标签
- [ ] 对照"四维差异化"检查：赛道是否垂直、人设是否有记忆点

**1.3 账号四件套（环2）**
- [ ] 昵称定稿（建议格式：XX城市+设计+专长词，全网同号）
- [ ] 头像：本人专业照（实拍，不推荐AI生成图）
- [ ] 一句话简介（人设+信任状+钩子，如"专注XX风格全案设计X年·帮XXX个家庭落地理想家·私信领《装修避坑手册》"）
- [ ] 背景图/主页装修：代表作实景图拼贴
- [ ] 小红书+抖音两个平台同步注册，信息完全一致（多平台信息一致原则）

**1.4 素材三库（环4）**
- [ ] 建文件夹：标题库 / 选题库 / 素材库（建议放"设计师MCN项目/02-内容资产"下）
- [ ] 标题库：从对标账号收集20条爆款标题
- [ ] 素材库：设计作品图、工地照片、材料图、金句（从532条避坑经验中摘）
- [ ] 选题库：从知设避坑经验库转出30条选题（痛点×场景化表达，我可以代做）

**1.5 对标研究（环8）**
- [ ] 用"四标准"筛选3-5个对标账号（关键词相似/涨粉速率/数据持久性/盈利能力）
- [ ] 拆解每个账号：视频开场前3秒、封面设计、内容结构、变现方式
- [ ] 记录一份对标笔记（每周更新一次）

---

## 第2周：内容周（环3能力 + 环4内容）

### 本周目标
选题清单确认、第一批内容生产、发布排期上线。

### 任务清单

**2.1 表达力测试（环3）**
- [ ] 设计师完成3次试拍（手机即可）：1条自我介绍、1条避坑口播、1条案例讲解
- [ ] 评估三项：出镜自然度（镜头当熟人）、口语化程度（说人话）、内容结构（3秒钩子开头）
- [ ] 定拍摄形式：真人出镜 / 半出镜（手部特写+实景）/ 图文卡片（根据设计师意愿）

**2.2 选题清单定稿（环4）**
- [ ] 从30条选题中选出首发10条，按内容三角配比：人设故事2条 + 专业干货6条 + 成果转化2条
- [ ] 每条选题写出：标题（用标题四技巧：简洁/价值/情感/悬念）+ 钩子前3秒 + 干货要点3-5条

**2.3 发布排期（环6）**
- [ ] 定发布节奏：建议每周3-5篇（起步期小红书为主，抖音跟进）
- [ ] 做一张内容日历：哪天发什么、什么选题（可用Excel/表格）
- [ ] 关键词布局：小红书搜索词清单（"XX城市装修""XX风格""装修避坑"等，把用户会搜的词写进标题和正文）

**2.4 内容生产SOP（环4）**
- [ ] 拍摄清单：每期内容需要什么素材（工地/案例图/口播文案）
- [ ] 剪辑流程：用什么工具、谁来剪（可先外包或我用AI辅助文案）
- [ ] 文案红线（写进SOP）：不编造出处、不引无实据数字、效果图标注"效果图仅供参考"、客户案例脱敏

---

## 第3周：运营周（环5信任 + 环7变现）

### 本周目标
评论区运营跑起来、种子粉丝启动、私域承接路径打通。

### 任务清单

**3.1 评论区运营（环5）**
- [ ] 建立回复话术库：专业答疑类、感谢类、引导私信类各5条模板
- [ ] 定回复纪律：发布后2小时内回复所有评论；每条评论当独立个体对待
- [ ] 主动互动：每天到3-5个同领域大V视频下留高质量评论（评论引流法，选10万粉以上账号）

**3.2 种子粉丝（环5）**
- [ ] 列种子粉丝清单：设计师的真实客户、朋友、同行20人
- [ ] 一对一邀请关注+给福利（免费避坑咨询/设计建议）
- [ ] 把每一条真实好评截图存档（客户见证素材）

**3.3 私域承接（环7）**
- [ ] 主页留微信路径：简介写"私信领资料"，私信自动回复引导
- [ ] 微信侧准备：工作号注册、朋友圈封面（人设+案例）、第一条朋友圈文案
- [ ] 咨询话术初稿：私信→加微信→需求诊断→约见面量房，每一步的话术模板

**3.4 数据看板（环8）**
- [ ] 建一个简单的数据表：每篇内容记录 阅读/点赞/收藏/评论/涨粉/私信
- [ ] 三个核心指标：内容阅读量、账号涨粉数、咨询私信数（每周五复盘）

---

## 第4周起：稳定期（环8坚持）

- [ ] 每周五固定复盘：数据看板更新 + 选题方向验证（哪类内容数据好就加量）
- [ ] 每月一次对标研究更新 + 失败六因自查（没聚焦/纯营销/照搬/不坚持/无底线/贩卖鸡汤）
- [ ] 第30天做一次中期检查：前10条最佳选题总结，验证人设标签是否有效
- [ ] 记住书里的时间预期：成果3个月显现，前期只拼持续性
