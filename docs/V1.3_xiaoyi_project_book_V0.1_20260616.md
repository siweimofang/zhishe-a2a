## 一、项目概述

### 1.1 项目名称

**知设 AI 装修顾问 · 鸿蒙小艺版**

### 1.2 项目愿景

**让 1.8 亿 HarmonyOS 鸿蒙用户在主对话说"装修",立刻得到沈阳本地 8 年老法师级别的装修 AI 顾问服务。**

### 1.3 项目使命

**在鸿蒙生态建立一个"知设"垂直于装修领域的 AI Agent 智能体,实现"用户根本不用搜,主对话自动弹"的零门槛装修咨询服务体验。**

### 1.4 核心价值观

1. **用户零门槛**:**用户不用搜,主对话自动调起**——这是 V1.3 在 5 大外壳中独有的"主对话调起"红利
2. **数据 100% 自留**:**Service Extension Ability 挂 zhishe-a2a 永久 URL**,数据完全在自留地
3. **底座 100% 复用**:**5 大外壳共用同一 zhishe-a2a 永久 URL + 同一内壳 LLM(DeepSeek-v4-pro)+ 同一知识库 V0.1(22 条)+ 同一 prompt V1.6(9 条行业认知铁律)**
4. **1 人创业铁则**:**V1.0 验证,V1.1-V1.4 复用,数据驱动优化**

### 1.5 项目一句话定位

**用 DevEco Studio 写 Service Extension Ability,把 zhishe-a2a 永久 URL 包成鸿蒙原生应用,挂到小艺主对话,实现"用户说装修 → 小艺自动弹知设"**。

## 二、项目背景

### 2.1 行业背景(沈阳装修行业 2026 Q2)

**与 V1.0 千问版 100% 复用,数据来源一致**:
- 沈阳装修市场 2026 Q2 价格基准:半包 350-1300 元/平,大包 700-5000 元/平
- 沈阳本地 3 大建材市场:浑南 / 铁西 / 皇姑
- 装修决策类咨询用户:中年为主,40-55 岁,装修预算 5-30 万,有时间主动找资料

### 2.2 市场机会(鸿蒙生态的 1.8 亿 DAU 红利)

**关键差异(对比 V1.0 千问主动搜)**:

| 维度 | V1.0 千问(用户主动搜) | **V1.3 小艺(主对话自动调起)** |

| 用户量级 | 千万级 | **1.8 亿 DAU** |
| 用户画像 | 深度装修用户(主动找资料) | **广撒网(从轻度到重度装修用户全覆盖)** |
| 触达深度 | 高(用户带着问题来) | **中(用户随口问)** |

### 4.3 数据流图(V1.3 端到端)

```
用户对 HarmonyOS 小艺说:"装修多少钱?"
   ↓ (0.5s 语音识别 + 文本化)
小艺主对话接收文本 + 关键词识别"装修"
   ↓ (0.5s 意图识别)
意图匹配"zhishe.renovation.quote" → 调 Service Extension Ability
   ↓ (1s 小艺智能体框架 2.0 路由)
Service Extension Ability 接收 user_query + intent_id
   ↓ (1s 启动 HTTP 请求)
HTTP POST https://tunnel.zhishe.top/v1/chat/completions
   ↓ (2-15s 内壳 LLM 调用 + 知识库检索)
zhishe-a2a 后端处理:
  - 接收请求
  - 鉴权(API Key 验证)
  - 知识库 V0.1 检索 22 条
  - 内壳 LLM(DeepSeek-v4-pro)调用
  - 答案生成
  - 加微信转化引导植入
   ↓
回传 JSON {choices: [{message: {content: "<完整答案>"}}]}
   ↓ (1s 小艺智能体框架 2.0 接收 + 格式化)
小艺主对话显示答案(用华为云的"鸿蒙智能体"UI 模板)
   ↓
用户看到答案 + 加微信引导
```

**总延迟**:**7-21s(端到端)**,对比 V1.0 千问 V1.5 9.9s / V1.6 21s(同内壳 LLM 同数据流)。
