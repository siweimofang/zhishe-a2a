## 第一性原理

文章的核心逻辑可以从第一性原理拆解为：

Agent = 通用推理能力 + 行业专业知识

- 通用推理能力 -> 由基座模型提供 -> 趋向商品化（开放权重追赶闭源，差距在缩小）
- 行业专业知识 -> 由Skill/知识资产提供 -> 差异化壁垒所在

因此，Agent经济的价值分配：模型层赚推理的钱，Skill层赚知识的钱。

这正是知设的战略定位：不做模型层（轻资产），做行业知识层（Gotchas库 + 设计师Schema）。模型可以换（5大外壳），但行业知识只此一家。

更深一层：文章揭示了Agent时代的"知识产权"问题 -- 当专业知识被封装成Skill并被调用时，如何确保知识创造者获得收益？这个问题如果解决不了，高质量知识的供给就会枯竭。知设的三层飞轮（撮合抽佣）本质上就是在解决这个分配问题。
