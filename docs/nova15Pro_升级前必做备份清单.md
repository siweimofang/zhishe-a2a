## 一、华为官方推荐的 3 种备份方式

### 方式 1:数据克隆(手机克隆,推荐)

**操作**:
1. nova 15 Pro 和备用机(或家人手机)放在同一 Wi-Fi 下
2. nova 15 Pro 打开"设置" → "系统和更新" → "手机克隆" → "这是新设备"
3. 备用机打开"手机克隆" → "这是旧设备"
4. 选 nova 15 Pro(新) → 扫备用机(旧)二维码
5. 选择"从安卓/iPhone 迁移" → 等待传输完成

**备份内容**:联系人 / 短信 / 通话记录 / 照片 / 视频 / 应用数据(部分)

### 方式 2:华为手机助手(PC 备份,完整)

**操作**:
1. PC 下载安装"华为手机助手"(`https://consumer.huawei.com/cn/support/pc-client/`)
2. USB 连接 nova 15 Pro(允许 HDB 调试)
3. 打开华为手机助手 → 点"数据备份"
4. 勾选所有项 → 点"开始备份"
5. 备份文件存到 PC 任意目录

**备份内容**:完整备份(联系人 / 短信 / 通话记录 / 照片 / 视频 / 应用 / 应用数据 / 设置)

### 方式 3:云备份(华为云)

**操作**:
1. nova 15 Pro 打开"设置" → "华为账号" → "云空间"
2. 启用"云备份"
3. 点"立即备份"
4. 等待备份完成(数据上传到华为云)

**备份内容**:核心数据(联系人 / 短信 / 通话记录 / 照片 / 视频 / 备忘录 / 日历)
