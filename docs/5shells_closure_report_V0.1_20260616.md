### 2.2 核心战略原则(5 大版本统一)

1. **"内壳 LLM = 动态战略资产,不是锁定资产"**:**5 大版本共用 DeepSeek-v4-pro**(当前),**未来能力强/价格低随时换**(Qwen-Plus / GLM-5.1 / MiniMax M3 等)
2. **"外壳 LLM = 平台自家品牌大模型"**:**V1.0=Qwen-Plus / V1.1=混元 Hy3 / V1.2=豆包 1.5 Pro / V1.3=盘古 / V1.4=GLM-5.1**——**只做"格式转换 + 安全审核",不参与答案生成**
3. **"数据 100% 走自留地"**:**5 大版本共用 zhishe-a2a 永久 URL**(**V1.0 弱自留 80% 锁百炼 / V1.1 中自留 50% 锁腾讯云 / V1.2-V1.4 强自留 100% 自留地**)
4. **"知识库 + Prompt 100% 复用"**:**22 条 V0.1 + 9 条 V1.6 行业铁律 = 5 大版本零迁移成本**
5. **"先到先得 > 死守护城河"**:**5 大平台先占坑,后续根据数据决定深耕哪个**

| 版本 | 自留地成熟度 | 实现路径 | 关键洞察 |

| V1.2 豆包 | **强**(100% 自留地) | 扣子工作流私有 API 节点,知识库不传扣子,prompt 不重写 | **V1.2 是"自留地策略"成熟版本,扣子工作流是关键工具** |

- **V1.0 弱 → V1.1 中 → V1.2-V1.4 强**:**5 大外壳自留地策略逐步成熟**
- **V1.2 扣子工作流是关键转折点**:**"平台 + 自留地"双轨策略从 V1.2 开始成熟**
