## 一、一句话战略

**知设 = 跨 5 大品牌的"装修垂直领域 Agent",内壳 = zhishe-a2a 后端(沈阳装修本地化 + 9 条行业认知铁律 + 报价引擎 + 知识库 V0.1),外壳 = 5 大 AI 平台智能体(V1.0 千问 / V1.1 元宝 / V1.2 豆包 / V1.3 小艺 / V1.4 智谱清言),每个外壳跑各家平台自家品牌大模型(LLM 互不锁定)。**

战略三要素:

1. **跨 5 大品牌** = 千问/元宝/豆包/小艺/智谱,5 个 AI 平台同步上架
2. **内壳 100% 复用** = zhishe-a2a 后端 + 9 条铁律 + 报价引擎 + 知识库 V0.1
3. **外壳 LLM = 平台自家** = V1.0 千问跑 Qwen,V1.1 元宝跑混元,V1.2 豆包跑豆包,V1.3 小艺跑 Pangu,V1.4 智谱跑 GLM-5.1

## 二、为什么"知设" = 跨 5 大品牌

知设的战略定位**不是"千问上的装修 Agent"**,而是**"跨 5 大品牌的装修垂直领域 Agent"**:

| V 编号 | 外壳品牌 | 平台 | 平台母公司 | 外壳 LLM |
|---|---|---|---|---|
| **V1.0** | 千问 | 千问 APP / 阿里百炼 | 阿里 | Qwen-Plus-Latest |
| **V1.1** | 元宝 | 元宝 APP / 腾讯元器 | 腾讯 | 混元 |
| **V1.2** | 豆包 | 豆包 APP / 字节扣子 | 字节 | 豆包 |
| **V1.3** | 小艺 | 鸿蒙 OS / 华为小艺开放平台 | 华为 | Pangu |
| **V1.4** | 智谱清言 | 智谱清言 Web/App / 智谱开放平台 | 智谱 | GLM-5.1 |

**核心逻辑**:

- **"知设" = 主体品牌**(跨 5 大平台通用)
- **"千问/元宝/豆包/小艺/智谱" = 平台品牌**(各管各家)
- 用户从哪个平台进来,看到的都是"知设"在回答
- 唯一区别:**底层 LLM 不同**(因为各家平台调自家 LLM)

## 三、内壳(100% 复用,不动)

**zhishe-a2a 后端统一引擎** 不论跑在哪个外壳上,内壳都是同一套代码、同一份知识、同一套报价逻辑。

### 3.1 内壳 4 大模块

1. **沈阳装修本地化业务知识**
   - 沈阳地区楼盘 / 户型 / 装修风格偏好
   - 沈阳本地施工队 / 建材商 / 监理资源
   - 沈阳本地报价行情(2026 Q2 行情基线)

2. **9 条行业认知铁律(小知 V1.6)**
   - 业主身份识别 / 预算锚定 / 量房验房 / 报价透明
   - 施工流程规范 / 主材辅材区分 / 增项漏项防御
   - 合同陷阱规避 / 售后维权路径

3. **报价引擎**
   - 代码位置:`app/services/quote.py`
   - 输入:面积 / 户型 / 装修档次 / 城市(沈阳)
   - 输出:分项报价清单(主材/辅材/人工/管理费/税费)

4. **知识库 V0.1**
   - 代码位置:`data/knowledge.json`
   - 规模:22 条(截至 2026-06-16)
   - 内容:沈阳本地楼盘 + 装修 FAQ + 9 条铁律展开

### 3.2 LLM 调用层(动态战略资产)

- 代码位置:`app/services/llm.py`
- 性质:**LLM 永远 = 动态战略资产**(非锁定)
- **当前内壳 LLM**:DeepSeek-v4-pro
- **未来可切换**:
  - 千问 Qwen-Plus-Latest(备选 1)
  - 智谱 GLM-5.1(备选 2,需评估)
  - 其他性价比更优的 LLM(随时评估)

## 七、4 件核心战略认知(2026-06-16 02:11 终版)

### 认知 1:外壳 LLM 跟内壳 LLM 是 2 件事,互不锁定

- **外壳 LLM** = 平台自家品牌大模型(Qwen/混元/豆包/Pangu/GLM-5.1)
  - 锁死在平台上,不可换(换了就跑不到那家平台)
- **内壳 LLM** = 你的 zhishe-a2a 后端调的 LLM(动态战略资产,当前 DeepSeek-v4-pro)
  - **不锁定**,随时可换
- 两者**互不锁定**:**V1.0 千问外壳调 Qwen 不影响你"内壳 LLM 动态"原则**

**举例说明**:
- V1.0 千问 = 外壳跑 Qwen-Plus(因为百炼只能调 Qwen)+ 内壳 DeepSeek-v4-pro
- V1.3 小艺 = 外壳跑 Pangu(因为小艺平台只能调 Pangu)+ 内壳 DeepSeek-v4-pro
- **内外壳 LLM 永远是 2 个不同的 LLM**(除非未来平台也支持 DeepSeek,但概率低)

### 认知 2:不同外壳对应不同品牌,平台自家 LLM 对应自家品牌大模型

- V1.0 千问外壳 = 阿里 Qwen 品牌
- V1.1 元宝外壳 = 腾讯混元品牌
- V1.2 豆包外壳 = 字节豆包品牌
- V1.3 小艺外壳 = 华为 Pangu 品牌
- V1.4 智谱外壳 = 智谱 GLM-5.1 品牌

**用户原话(2026-06-16 02:11)**:"早该这样(是不是不同的外壳对应不同的品牌,平台自家 LLM 对应自己的品牌大模型)"

**深层含义**:
- 每个外壳对应该平台的"品牌资产"
- 平台 LLM 调自家品牌 = 平台生态闭环最优
- 业主在 V1.3 小艺看到的"知设回答"是 Pangu 生成的,但业务逻辑(沈阳装修本地化 + 9 条铁律)是内壳 DeepSeek 处理的
- 业主感知 = 平台 LLM 风格 + 知设业务内核

### 认知 3:内壳 LLM 是动态战略资产,不是锁定资产

- **当前**:DeepSeek-v4-pro(性价比最优)
- **未来**:能力变弱或价格上涨,随时换
- **不锁定** = 战略灵活性

- 备选 2:智谱 GLM-5.1(技术备选,需评估)
- 备选 3:其他新 LLM(随时评估)

### 认知 4:"知设"是跨 5 大品牌的真正定位

- **5 大平台上的"装修 AI 顾问"都是知设**
- "知设"是**主体品牌**(跨平台)
- "千问/元宝/豆包/小艺/智谱"是**平台品牌**(各管各的)
- 用户在 5 大平台看到的"知设"表现是"该平台 LLM + 沈阳装修本地化知识"

**品牌资产沉淀逻辑**:
- 业主在 V1.0 千问搜"知设" → 看到"知设" + Qwen 风格
- 业主在 V1.3 小艺搜"装修" → 小艺自动调起"知设" → 看到"知设" + Pangu 风格

## 八、风险与对策

### 8.1 流量风险

- **风险**:5 个平台用户重叠度低(千问/元宝/豆包/小艺/智谱用户基本不重叠)
- **影响**:单平台流量天花板有限
- **对策**:**5 个都做,不要押注单一平台**
  - 5 个平台用户叠加 = 理论月活天花板 5+ 亿
  - 任意 1 个平台流量下跌不影响整体

### 8.2 LLM 切换风险

- **风险**:内壳 LLM 动态,切换需要重测(报价引擎 / 9 条铁律 / 知识库 V0.1)
- **影响**:LLM 切换可能影响回答质量
- **对策**:**保留 2 个备选 LLM**(DeepSeek-v4-pro + 千问 Qwen-Plus),有备无患
  - 切换时跑 A/B 测试,对比 9 条铁律回答准确率
  - 准备 LLM 切换 SOP 文档

### 8.3 上架审核风险

- **风险**:5 个平台都要审核(1-7 天/平台),任意 1 个卡住影响进度
- **影响**:上架延期
- **对策**:**并行提交**,不等 1 个通过再做下 1 个
  - 5 个平台同时提交审核
  - 准备 5 套上架材料(产品介绍 / 截图 / 协议对接文档)

### 8.4 数据护城河风险

- **风险**:**5 大平台数据完全归平台所有**(跟千问 V1.0 一样)
  - 业主对话数据 / 行为数据 / 偏好数据都归平台
  - 知设拿不到原始数据
- **影响**:数据资产沉淀在平台,不在知设
- **对策**:**私域沉淀**
  - 知设小程序独立产品线(不在外壳体系)
  - 微信公众号(内容运营)
  - 业主私域微信群(深度服务)
  - **私域才是知设的真正数据护城河**

### 8.5 LLM 价格波动风险

- **风险**:内壳 LLM(DeepSeek-v4-pro)价格上涨,影响成本
- **影响**:单次报价成本上升
- **对策**:
  - 监控 DeepSeek API 价格(季度复盘)
  - 备选 LLM(Qwen-Plus)价格对比
  - 必要时切换 LLM(认知 3 原则)

### 8.6 平台政策风险

- **风险**:任意 1 个平台政策调整(下架 / 限流 / 改协议)
- **影响**:单平台流量归零
- **对策**:**5 个平台分散风险**,单平台下架不影响整体
  - 微信小程序 + 公众号作为**完全独立的产品线**,不依赖任何 AI 平台
