> 目标: 系统化、可持续、低投入的内容增长

---

## 🎯 核心原则

1. **不靠"我每周想一条"** —— 是数据驱动的飞轮
2. **3 个时间维度并行**:
 - **周度**(2h):真实对话挖掘
 - **月度**(4h):老板领域经验输入
 - **季度**(8h):市场行情/政策变化
3. **总投入** = 每月 8-16h = 1 人业余时间够用
4. **数据飞轮**:用户问得越多 → 答得越准 → 用户越多

---

## 📅 季度主循环(12 周 = 1 季度)

### 完整流程

| 周 | 任务 | 投入 | 产出 |
|---|---|---|---|
| **W1-2** | 收集当季用户真实对话(top 50 问) | 1h/周 | 50 条新问答候选 |
| **W3-4** | 老板审 + 改写为知识库条目 | 4h/周 | **20-30 条精修知识** |
| **W5-8** | 每月新增 100-200 条,做分类标签 | 1h/周 | 月度 100 条新增 |
| **W9-10** | **季度大盘点**:数据更新(价格基线/系数) | 8h/季度 | 报价数据刷新 |
| **W11** | 跑压力测试(LLM 注入新版数据) | 2h | 验证答得对 |
| **W12** | **发布新版本**(V1.6 / V1.7 / V1.8 ...) | 1h | git commit + 上线 |

## 📊 3 路内容来源(配比)

### 路 1:真实用户对话挖掘(60%)
**做法**:
- 周一:导出百炼应用"观测"页 top 20 真实对话
- 周三:筛选"高频问但答得不好"的对话
- 周四:做成知识库新条目

**配 3 个工具**(Mavis 实现):
- `app/services/chat_analytics.py`:统计"哪些问题被问最多"
- `app/services/answer_quality.py`:检测"LLM 答得短/没分项/没问方式档次"
- 自动生成"待补充条目"列表,老板审

### 路 2:老板领域经验输入(30%)
**做法**:
- **每月 1 次**,集中 4 小时
- 老板口述 / Mavis 整理成"业务认知铁律"格式
- 直接进 `app/prompts/xiaozhi.py` 的"行业认知铁律"段

**好处**:**1 次说 5 条,管 3 个月**

**已发生实例**:
- 2026-06-13 08:09 老板指出"装修不是房地产"
- 2026-06-13 09:02 老板给出"半包/大包/全案 + 4 档"完整数据
- 2026-06-13 09:09 老板补充"报价两种场景"
- 2026-06-13 17:02 老板深度修正"水电按米数虚高机制" + "全屋定制两阶段"

### 路 3:市场行情变化(10%)
**频率**:**季度盘点** 1 次(每 3 个月)
- 沈阳建材市场新店 / 价格波动 / 政策变化
- 改 `data/quote_baseline.json` + `data/coefficients.md`

**为什么 10%**:**装修行情半年到一年才动一次**,过度更新反而让历史对话对不上。

| 频率 | 更新内容 | 谁负责 |
|---|---|---|
| **季度** | `data/quote_baseline.json`(基础价 12 项) | 老板(行业经验) + Mavis 整理 |
| **半年** | `data/coefficients.md`(户型/风格系数) | 老板 |

**理由**:装修行情半年到一年才动一次。季度更新基础价够用。

## 📋 月度运营 checklist(老板侧)

### 每月第 1 周(周一上午,1h)
- [ ] 跑 `chat_analytics`,看"上月高频问题 top 20"
- [ ] 看"上月低质量回答 top 10"
- [ ] 列"本月要新增的知识条目"(10-15 条)

### 每月第 2 周(4h,集中)
- [ ] 老板口述 5-10 条"业务认知"(可以是新坑、新工艺、新政策)
- [ ] Mavis 整理进 `xiaozhi.py` 或 `knowledge.json`
- [ ] 跑 1 次端到端测试验证

### 每月第 3 周(1h)
- [ ] 看 `knowledge_pending.json`(待审条目)
- [ ] 标"通过"或"驳回"
- [ ] 跑 pytest 确认没破

### 每月第 4 周(2h)
- [ ] git commit 月度更新
- [ ] 看 `uvicorn.log` 找异常
- [ ] 给种子用户发月度更新通知(如果有)

## 🗓 季度运营 checklist(老板侧)

- [ ] **价格基线更新**: `data/quote_baseline.json`

- [ ] **版本号更新**: V1.x → V1.(x+1) 或 V2.0

- [ ] 看 `uvicorn.log` 找 p95 延迟

### 每季度第 3 个月底(1h)
- [ ] git tag 版本
- [ ] 备份 `data/` 到云端
- [ ] 写季度总结(发到用户 / 朋友圈)
