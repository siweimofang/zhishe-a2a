## 一、ICP 备案 5 个核心事实(必读)

### 1.1 ICP 备案 = 网站在中国大陆的"网络身份证"

- **法律依据**:`《互联网信息服务管理办法》` 工信部主管
- **没备案 = 关停**(网站不能上线中国大陆)
- **必须 5-10 天前提交**(小艺平台过渡期 3 个月 = 9 月底前完成)

### 1.2 ICP 备案 3 大要素

| 要素 | 你的情况 | 状态 |
|---|---|---|
| **域名**(中国大陆可访问) | zhishe.top(阿里云)+ tunnel.zhishe.top(Cloudflare) | ✅ 已有 |
| **服务器**(中国大陆境內) | 腾讯云上海(或阿里云 ECS) | ✅ 已有 |
| **备案主体**(中国大陆企业/个人) | 沈阳赫慕空间设计有限责任公司(法人:马壮男) | ✅ 已有 |

### 1.3 辽宁省备案的优势(沙箱实证)

| 维度 | 辽宁省 | 全国平均 |
|---|---|---|
| **审核周期** | **5-10 个工作日** | 1-2 周 |
| **审核宽松度** | "不算太严格,审核速度还可以" | 中等 |
| **辽宁统一管理** | 沈阳/大连/鞍山/抚顺... 全部统一提交省管局 | — |

**结论**:走辽宁省 = 备案最快 + 政策友好

### 1.4 ICP 备案和 ICP 许可证的区别

| 类型 | 用途 | 知设需要? |
|---|---|---|
| **ICP 备案**(非经营性) | 个人/企业网站 | ✅ **需要**(你是企业咨询类网站) |
| **ICP 许可证**(经营性) | 付费/收费网站 | ❌ 不需要(你不是收费内容) |

**你的 ICP 备案 = 非经营性**,门槛低、流程快。

### 4.2 zhishe-a2a 后端 API 加 ICP 备案号头

```python
# app/main.py 加 middleware
ICP_INFO = {
    "icp": "辽ICP备XXXXXXXX号-1",
    "police": "辽公网安备 XXXXXXXX 号"
}

@app.middleware("http")
async def add_compliance_headers(request, call_next):
    response = await call_next(request)
    response.headers["X-ICP-License"] = ICP_INFO["icp"]
    response.headers["X-Police-License"] = ICP_INFO["police"]
    return response
```

## 六、5 大高频踩坑(沙箱实证)

### ⚠️ 踩坑 1:域名持有者 = 备案主体

**症状**:zhishe.top 在阿里云注册时用了个人实名,公司备案会被驳回。

**避免**:检查 zhishe.top WHOIS,持有人 = "沈阳赫慕空间设计有限责任公司"。

### ⚠️ 踩坑 2:短信核验 24 小时

**症状**:错过核验 = 自动退回 = 重来 1-2 周。

**避免**:提交后 24 小时内盯手机短信,第一时间核验。

### ⚠️ 踩坑 3:网站负责人 ≠ 法人

**症状**:如果用员工,需要额外上传授权书(盖章)。

**避免**:网站负责人 = 法人 = 马壮男,无需授权书。

### ⚠️ 踩坑 4:阿里云 ECS 必须有公网 IP

**症状**:没公网 IP = 备案驳回。

**避免**:99 元经济型 e 实例自带公网 IP,确认已分配。

### ⚠️ 踩坑 5:Cloudflare 域名要中国实名

**症状**:Cloudflare 域名如果不完成中国实名,可能影响备案。

**避免**:登录 Cloudflare → 域名管理 → 注册商设置 → 添加中国实名信息。
