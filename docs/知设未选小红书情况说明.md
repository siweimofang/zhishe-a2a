## 一、平台基本信息
- 平台名: 小红书(点点 AI 助手)
- 母公司: 行吟信息科技(上海)有限公司
- 主对话 LLM: 自研(点点)
- 智能体平台名: ❌ **未公开支持**(点点)
- URL: https://open.xiaohongshu.com

## 二、第三方 Agent 入驻支持(沙箱实查 2026-06-16)
- 是否支持第三方 Agent 入驻/上架: ❌ **未公开支持**
- 主对话是否自动调第三方 Agent: ❌ **未公开支持**
- 入驻门槛(企业认证/资质要求): 装修行业强监管 — 营业执照 + 4 选 1 行业资质 + 600 元审核费
- 流量规模: 客服消息接口可用,需企业认证

## 三、未选原因
1. 装修行业是**强监管行业** — 需《工程设计与施工资质证书》或同等,你有营业执照但 4 选 1 行业资质未知
2. **严禁导流私域** — 跟你 V1.0 千问版转化话术"加微信/拍淘宝"冲突
3. 装修咨询类输出在 4 个禁区之列,只能做"效率工具/内容辅助/SaaS/数据洞察"4 个方向

## 四、未来重启条件
满足以下**任一**条件可重启该项目:
- 条件 1: 点点开放第三方 Agent 入驻/上架
- 条件 2: 你获取《工程设计与施工资质证书》或同等资质
- 条件 3: 你的 V1.0 千问版转化路径改成"小红书内私信/服务留资卡"(放弃加微信)
- 条件 4: 政策变化允许"加微信"导流

## 五、相关事实链(沙箱验证)
用户 2026-06-16 实查小红书点点开放平台,原文引用:
- "小红书'点点 AI 助手'目前没有公开的第三方 Agent 开放文档"
- "装修/设计属于平台强监管行业,必须完成以下认证才能合规运营"
- "严禁导流私域,不能在笔记/评论区/私信中引导加微信、VX、电话等"

补充事实(出处同上):
- 小红书装修行业入驻需"营业执照 + 4 选 1 行业资质(《工程设计与施工资质证书》/ 设计协会会员 / 平台邀约码 / 品牌授权)+ 600 元审核费",资质门槛高于普通行业
- 装修咨询类内容被列入"医疗/金融/法律/装修"4 大禁区,只能走"效率工具/内容辅助/SaaS/数据洞察"4 个安全方向
- V1.0 千问版转化话术核心是"加微信详谈/拍淘宝商品链接",与小红书"严禁导流私域"规则正面冲突,直接违反将导致笔记下架甚至账号封禁
- Project Context 显示 zhishe-a2a 当前主战场是"千问 AI Agent 智能体广场",小红书仅在"待评估"列表

结论:小红书点点既缺第三方 Agent 入驻通道,又对装修行业有强监管 + 反导流双约束,与 V1.0 千问版的"私域转化"模型不兼容,因此归档为"未选 + 重启门槛高"。
