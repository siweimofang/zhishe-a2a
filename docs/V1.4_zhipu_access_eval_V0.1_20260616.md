## 3. 路径选择(从"自留地"到"智谱清言主对话")

### 路径 A(主推):GLM 智能体 SDK + 私有 API 挂 zhishe-a2a

```
[智谱清言 APP/网页/小程序用户]
   ↓ 主动搜"装修" / "知设" / 主对话关键词"装修"自动调起
[智谱智能体广场 → "知设 AI 装修顾问"]
   ↓ 进入智能体
[GLM 智能体 SDK - 私有 API 路由]
   ↓ 调"知设装修咨询"私有 API 节点
[zhishe-a2a 永久 URL https://tunnel.zhishe.top/v1/chat/completions]
   ↓ (内壳 LLM = DeepSeek-v4-pro,知识库 V0.1 注入)
[回传答案]
   ↓
[GLM 智能体 → 智谱清言用户]
```

**优势**:
- **数据 100% 走自留地**(核心战略 — 不锁定任何平台)
- **GLM 智能体 SDK 原生支持挂私有 API**(5 大外壳中自留地策略最成熟)
- **知识库 V0.1 + prompt V1.6 直接复用**(V1.0 千问 V1.1 元宝 V1.2 豆包 V1.3 小艺 0 损耗)
- **内壳 LLM 永远是 DeepSeek-v4-pro**(动态战略资产,GLM-5.1 只做"格式转换")
- **主对话自动调起**(跟 V1.3 小艺同档)

**劣势**:
- 智谱开放平台实名认证(1-3 天)
- 智能体上架审核(1-3 天)
- 私有 API 配置需 GLM 智能体 SDK 熟悉度(30-60 min 学习)

### 路径 B(备选):智谱清言智能体广场 + GLM-5.1 直答

```
[智谱清言 APP 用户]
   ↓ 主动搜"装修" / "知设"
[智谱智能体广场 → "知设 AI 装修顾问"]
   ↓ 进入智能体
[GLM-5.1 直答]
   ↓ (外壳 LLM = GLM-5.1,知识库传智谱云)
[回传答案]
```

**优势**:
- 配置简单(20 min 用户搞定)
- 无需 GLM 智能体 SDK 私有 API 配置

**劣势**:
- **数据 100% 锁智谱云**(违背"自留地"战略核心)
- **知识库要上传到智谱云**(重复劳动,跟 V1.0/V1.1/V1.2/V1.3 脱钩)
- **prompt 要在智谱平台重写一份**(跟 V1.0/V1.1/V1.2/V1.3 维护 5 份)
- **主对话调起不确定**(路径 B 不一定主对话自动调起)

### 路径 C(不推荐):走智谱开放平台 BIGModel 私有化部署

**说明**:**智谱 BIGModel 私有化部署**定位"B 端企业级",**不开放 C 端智能体独立发布**;**所有"智谱清言智能体"实质都是 GLM 智能体 SDK + 私有 API 路径**。**路径 C 不可行**。

### 决策矩阵

| 维度 | 路径 A(GLM 智能体 SDK + 私有 API) | 路径 B(GLM-5.1 直答) | 路径 C(私有化部署) |
|---|---|---|---|
| 数据自留 | ✅ **强(SDK 原生支持)** | ❌ 弱 | ❌ 不可行 |
| 知识库复用 | ✅ 100% 复用 V0.1(不传智谱云) | ❌ 需重传 | ❌ 不可行 |
| Prompt 复用 | ✅ 100% 复用 V1.6 | ❌ 需重写 | ❌ 不可行 |
| **主对话自动调起** | ✅ 强(主对话关键词) | ❌ 弱(可能不调起) | ❌ 不可行 |
| B 端高端用户触达 | ✅ 强(主对话 + 智能体广场双路径) | 中(智能体广场) | ❌ 不可行 |
| 配置工作量 | 中(30-60 min SDK) | 小(20 min) | 不可行 |
| 实名认证 | 必需(1-3 天) | 必需(1-3 天) | 不可行 |
| 上架审核 | 1-3 天 | 1-3 天 | 不可行 |
| 战略契合度 | ✅ **100%(自留地 + 内壳动态 + 主对话调起)** | ❌ 50% | ❌ 0% |
| 跟 V1.0/V1.1/V1.2/V1.3 一致性 | ✅ **100%** | ❌ 50% | ❌ 0% |

**我的建议**:**路径 A 为主推**。**V1.4 路径 A 是 5 大外壳中"自留地策略最成熟 + 主对话自动调起 + 审核最快 + 变现路径最强"四优版本**。

## 4. 模型选型

### 4.1 路径 A 下的"内壳/外壳"分工

**关键判断**:路径 A 下,**智谱清言"GLM-5.1"只负责"意图识别 + 格式转换 + 安全审核"**,**真正的"内壳 LLM"还是 DeepSeek-v4-pro**(从自留地走)。

| 模型 | 角色 | 备注 |
|---|---|---|
| **智谱清言"GLM-5.1"** | 外壳 LLM(意图识别 + 格式转换) | 智谱云,**几乎不参与答案生成** |
| **zhishe-a2a "DeepSeek-v4-pro"** | **内壳 LLM(答案生成主力)** | 100% 复用 V1.0 |
| **GLM-5.1 备选(可选)** | 备选(复杂推理) | 私有 API 挂 2 节点 |
| **第三方模型(Qwen-Plus / 混元 / ...) | 备选 | 暂不用 |

### 4.2 路径 B(GLM-5.1 直答)的"外壳 LLM"直接出答案

| 模型 | 适用场景 | 备注 |
|---|---|---|
| **GLM-5.1** | V1.4 路径 B 默认(主推) | 128k 上下文,深度思考,工具调用 |
| **GLM-5-Turbo** | 备选(轻量/省钱) | 速度快,但装修深度可能不够 |
| **GLM-5V-Turbo** | 备选(多模态) | 适合"户型图识别"等场景 |
| **GLM-5** | 备选(稳定版) | 适合"长期稳定"场景 |
| **第三方模型** | 备选 | 智谱支持,暂不用 |

### 4.3 选型决策(以主推路径 A 为准)

| 决策 | 选项 | 我的建议 |
|---|---|---|
| 智谱清言"意图识别" | GLM-5.1(默认) | **YES** |
| 内壳 LLM(zhishe-a2a) | DeepSeek-v4-pro | **YES**(V1.0 已在用) |
| 备选"复杂推理"模型 | GLM-5.1 + GLM-5V-Turbo(多模态) | **可加**(私有 API 挂 2 节点) |

**说明**:**跟 V1.0/V1.1/V1.2/V1.3 "内壳 LLM 动态战略资产"理念一致** — **外壳 LLM = 平台自家(智谱=GLM-5.1)**,**内壳 LLM = 动态战略资产(当前 DeepSeek-v4-pro)**。
