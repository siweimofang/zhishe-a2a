## 文件 1:`entry/src/main/ets/serviceability/RenovationConsultAbility.ets`

**位置**:DevEco Studio 项目 → `entry/src/main/ets/serviceability/`
**操作**:**右键 → New → Directory → 命名 `serviceability` → 在目录下创建 `RenovationConsultAbility.ets`**

**用户复制以下全部内容**:

```typescript
import { AbilityConstant, ConfigurationConstant, UIAbility, Want } from '@kit.AbilityKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
import { http } from '@kit.NetworkKit';
import { BusinessError } from '@kit.BasicServicesKit';

const DOMAIN = 0x0000;
const TAG = 'RenovationConsultAbility';

// zhishe-a2a 永久 URL + API Key
const ZHISHE_A2A_URL = 'https://tunnel.zhishe.top/v1/chat/completions';
const ZHISHE_API_KEY = 'mKgd4EVhF7A8Y9zk6unOyb2jI1NBLaTR';

export default class RenovationConsultAbility extends UIAbility {
  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam) {
    hilog.info(DOMAIN, TAG, 'RenovationConsultAbility onCreate');

    // 接收小艺主对话传来的"用户问题" + 意图 ID
    const userQuery = want.parameters?.user_query as string;
    const intentId = want.parameters?.intent_id as string;
    const sessionId = want.parameters?.session_id as string;

    // 意图路由
    if (intentId === 'zhishe.renovation.intro' ||
        userQuery?.includes('你好') ||
        userQuery?.includes('在吗') ||
        userQuery?.includes('介绍')) {
      // 首次对话:走"提示词自我介绍"分支
      this.selfIntroduction();
    } else if (intentId === 'zhishe.renovation.wechat' ||
               userQuery?.includes('加微信') ||
               userQuery?.includes('联系方式') ||
               userQuery?.includes('咨询')) {
      // 转化引导分支
      this.wechatGuide();
    } else {
      // 其他意图:调 zhishe-a2a 永久 URL
      if (userQuery) {
        this.callZhisheA2A(userQuery, sessionId);
      }
    }
  }

  async callZhisheA2A(userQuery: string, sessionId: string) {
    const httpRequest = http.createHttp();

    const requestBody = {
      model: 'deepseek-v4-pro',
      messages: [
        {
          role: 'user',
          content: userQuery
        }
      ],
      max_tokens: 1500,
      temperature: 0.7,
      stream: false
    };

    try {
      const response = await httpRequest.request(ZHISHE_A2A_URL, {
        method: http.RequestMethod.POST,
        header: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${ZHISHE_API_KEY}`
        },
        extraData: JSON.stringify(requestBody),
        connectTimeout: 60000,
        readTimeout: 60000
      });

      if (response.responseCode === 200) {
        const result = JSON.parse(response.result as string);
        const answer = result.choices[0].message.content;

        // 通过 hilog 输出,小艺智能体框架会自动捕获
        hilog.info(DOMAIN, TAG, `zhishe-a2a answer: ${answer}`);

        // 可选:写入 HarmonyOS 分布式数据(给后续 Service Extension Ability 调用)
        // dataPreferences.putStringSync('last_answer', answer);
      } else {
        hilog.error(DOMAIN, TAG, `zhishe-a2a HTTP ${response.responseCode}`);
      }
    } catch (err) {
      const error = err as BusinessError;
      hilog.error(DOMAIN, TAG, `zhishe-a2a error: ${error.code} ${error.message}`);
    } finally {
      httpRequest.destroy();
    }
  }

  selfIntroduction() {
    const intro = `👋 您好!我是「知设 AI 装修顾问」。
我是沈阳本地装修 AI,8 年老法师经验,服务过 200+ 沈阳业主。
我能帮您:
• 📊 出 2026 Q2 沈阳本地真实装修报价(4 档,半包/大包/全案)
• 📋 给装修全流程节点(量房 → 设计 → 拆改 → ... → 入住)
• 🛡️ 给水电/瓦/木/油 4 道工序的避坑指南(老法师经验)
• 🛒 推沈阳本地建材市场(浑南/铁西/皇姑 3 大市场对照表)

数据来源:国标 GB 50327-2001 / GB 50150-2016 / 伟星 vasen.com 防伪官网 / 沈阳本地 2026 Q2 实测价。
免责声明:不替用户做最终决定,所有信息仅供参考,签约前请以实际勘察和合同为准。`;
    hilog.info(DOMAIN, TAG, `intro: ${intro}`);
  }

  wechatGuide() {
    const guide = `装修水深,我整理了一份《2026 沈阳装修报价清单》PDF,加我微信 sxxxxx 发你。`;
    hilog.info(DOMAIN, TAG, `wechat guide: ${guide}`);
  }

  onDestroy() {
    hilog.info(DOMAIN, TAG, 'RenovationConsultAbility onDestroy');
  }

  onConfigurationUpdated(newConfig: ConfigurationConstant.Configuration) {
    hilog.info(DOMAIN, TAG, 'RenovationConsultAbility onConfigurationUpdated');
  }
}
```

**关键参数**:
- `ZHISHE_A2A_URL` = `https://tunnel.zhishe.top/v1/chat/completions`(永久 URL)
- `ZHISHE_API_KEY` = `mKgd4EVhF7A8Y9zk6unOyb2jI1NBLaTR`(Bearer Token)
- `model: 'deepseek-v4-pro'` = 内壳 LLM(自留地)
- `max_tokens: 1500` + `temperature: 0.7`(配合 V1.6 prompt 实测)

```json
    "mainElement": "EntryAbility",
    "deviceTypes": [
      "phone",

      "2in1",
      "wearable",
      "tv",
      "car"
    ],

    "installationFree": false,
    "srcEntry": "ets/entryability/EntryAbility.ets",
    "abilities": [
      {
        "name": "EntryAbility",
        "srcEntry": "ets/entryability/EntryAbility.ets",
        "description": "$string:EntryAbility_desc",
        "icon": "$media:icon",
        "label": "$string:EntryAbility_label",
        "startWindowIcon": "$media:icon",
        "startWindowBackground": "$color:start_window_background",
        "exported": true,
        "skills": [
          {
            "entities": ["entity.system.home"],
            "actions": ["action.system.home"]
          }
        ]
      },
      {
        "name": "RenovationConsultAbility",
        "srcEntry": "ets/serviceability/RenovationConsultAbility.ets",
        "description": "知设装修咨询服务",
        "icon": "$media:icon",
        "type": "service",
        "exported": true,
        "skills": [
          {
            "entities": ["entity.ability.intent"],
            "actions": ["action.ability.intent"],
            "uris": [
              {
                "scheme": "zhishe",

            ]

        ]

  }

```

**关键字段**:
- `type: "service"` = Service Extension Ability(关键)
- `actions: ["action.ability.intent"]` = 小艺意图识别自动调起(关键)
- `uris: scheme: "zhishe"` = 自定义 URI scheme
- `deviceTypes: 6 类` = phone/tablet/2in1/wearable/tv/car(满足华为 ≥ 3 类要求)

| 步骤 | 动作 | 预期 |
|---|---|---|
| 1 | DevEco Studio "Build" → "Rebuild" | ✅ 编译通过 |

## 排错对照表(出问题先看这里)

| 错误现象 | 原因 | 解决 |
|---|---|---|
| 编译报错"Cannot find module" | oh-package.json5 依赖没装 | DevEco Studio "File" → "Sync and Refresh" |
| 模拟器无响应 | Service Extension Ability 没注册 | 检查 module.json5 的 abilities 数组 |
| HTTP 401 错误 | API Key 配错 | 检查 `ZHISHE_API_KEY` 是不是 `mKgd4EVhF7A8Y9zk6unOyb2jI1NBLaTR` |
| HTTP 403 错误 | Cloudflare 边缘拦非浏览器 UA | 这是已知问题(参见 V1.0 沙箱验证报告),HarmonyOS http 模块的 UA 默认就是非浏览器,需要联系 Mavis 加 WAF 例外 |
| HTTP 404 错误 | URL 配错 | 检查 `ZHISHE_A2A_URL` 是不是 `https://tunnel.zhishe.top/v1/chat/completions` |
| HTTP 530 错误 | Cloudflare 边缘抽风 | 重试一次(临时问题) |
| 模拟器返回空 | `callZhisheA2A` 没被调用 | 检查 `onCreate` 的意图路由逻辑 |
| 答案超 1500 token 被截 | max_tokens 太小 | 把 `max_tokens: 1500` 改成 `max_tokens: 2000` |

**如果遇到 HTTP 403 问题(Cloudflare 拦非浏览器 UA)**:这是已知问题(V1.0 沙箱验证发现),**需要联系 Mavis 在 Cloudflare Zero Trust 加 WAF 例外**(15 分钟),**V1.3 上线后此问题会修复**。
