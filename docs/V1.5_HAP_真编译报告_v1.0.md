## 四、关键技术发现(沙箱实证)

### 4.1 HOS vs OHOS 两套元数据系统

**HarmonyOS (HOS)** 用 `sdk-pkg.json` + metaVersion 1.0.0/1.0.1
**OpenHarmony (OHOS)** 用 `oh-uni-package.json` + metaVersion 3.0.0/3.0.1

**D 盘 SDK 仓真值**:
- `D:\Huawei\SDK\20\` = OpenHarmony 4.x 仓(oh-uni-package.json × 5)
- `D:\Huawei\SDK\26.0.0\` = HarmonyOS 26 元数据(只有 sdk-pkg.json)
- `D:\Huawei\SDK\6.0.0\` = DevEco Studio 完整安装(被错误命名为 "SDK\6.0.0\")

### 4.2 build-profile.json5 格式规则

| 字段 | OpenHarmony 配置 | HarmonyOS 配置 |
|------|------------------|-----------------|
| `targetSdkVersion` | API 10-25: number(如 `12`),API 26+: string(如 `"26.0.0"`) | string(如 `"5.0.0(12)"` API 10-25,`"26.0.0"` API 26+) |
| `compatibleSdkVersion` | 同上 | 同上 |
| `compileSdkVersion` | **必须 number**(仅 OpenHarmony 用) | 不需要(HarmonyOS 自动从 sdk-pkg.json 读) |
| `runtimeOS` | "OpenHarmony" 或 省略 | "HarmonyOS"(必须显式)|

### 4.3 ArkTS 严格模式禁用清单

- `any` 类型
- `unknown` 类型(部分场景)
- 对象字面量未关联 interface/class
- `Record<string, any>` 索引签名

**替代方案**:显式定义 interface,字段类型逐一标注

### 4.4 hvigor 编译阶段

1. **PreBuild** — 配置文件校验
2. **CreateModuleInfo** — 模块信息生成
3. **GenerateMetadata** — 元数据生成
4. **MergeProfile** — 配置文件合并
5. **CreateBuildProfile** — 构建配置生成
6. **CompileResource** — 资源编译
7. **CompileArkTS** — ArkTS 编译
8. **BuildJS** — JS 包构建
9. **PackageHap** — HAP 打包(**需 Java daemon**)
10. **SignHap** — HAP 签名

**关键**:Java daemon 启动需要 `D:\Huawei\DevEco Studio\tools\hvigor\hvigor\lib\hvigor-java-daemon.jar` + 系统中 `java` 命令在 PATH
