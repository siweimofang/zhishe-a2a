## 2. GLM 智能体 SDK + 私有 API 配置(核心 - 路径 A 主推)

### 2.1 架构设计(用户配置)

**关键洞察**:**V1.4 跟 V1.3 小艺的"主对话自动调起 + 自留地"双优策略 100% 一致**——只是 SDK/IDE 工具不同;**V1.4 多出 3 个核心优势:审核最快(1-3 天)+ 数据自留最成熟(SDK 原生支持挂私有 API)+ 变现路径最强(B 端高端)**。

#### 完整架构图

```
[智谱清言 APP/网页/小程序用户]
   ↓ 主动搜"装修" / "知设" / 主对话关键词"装修"自动调起
[智谱智能体广场 → "知设 AI 装修顾问"]
   ↓ 进入智能体
[GLM 智能体 SDK - 私有 API 路由]
   ↓ 调"知设装修咨询"私有 API 节点
[zhishe-a2a 永久 URL https://tunnel.zhishe.top/v1/chat/completions]
   ↓ (内壳 LLM = DeepSeek-v4-pro,知识库 V0.1 注入)
[回传答案]
   ↓
[GLM 智能体 → 智谱清言用户]
```

#### GLM 智能体 SDK 私有 API 配置(用户操作)

**智谱开放平台 → 智能体广场 → + 创建智能体 → 基础信息**(填第 1 节内容)

**智谱开放平台 → 智能体广场 → 工具配置 → + 添加工具 → 自定义 API**:

| 字段 | 值 |
|---|---|
| **工具名称** | 知设装修咨询 |
| **工具描述** | 调用 zhishe-a2a 永久 URL,获取沈阳本地装修 AI 顾问的深度答案 |
| **工具类型** | **自定义 API(私有 API)** |
| **请求方法** | `POST` |
| **URL** | `https://tunnel.zhishe.top/v1/chat/completions` |
| **请求头** | `Content-Type: application/json`<br>`Authorization: Bearer mKgd4EVhF7A8Y9zk6unOyb2jI1NBLaTR` |
| **请求体(JSON)** | 见下方 |
| **超时** | 60 秒(智谱默认) |
| **响应处理** | 取 `choices[0].message.content` 字段 |

**请求体 JSON(用户复制)**:
```json
{
  "model": "deepseek-v4-pro",
  "messages": [
    {
      "role": "user",
      "content": "{{user_query}}"
    }
  ],
  "max_tokens": 1500,
  "temperature": 0.7,
  "stream": false
}
```

**说明**:
- `{{user_query}}` 是智谱智能体 SDK 的"用户输入"变量(智谱智能体广场支持)
- `model: "deepseek-v4-pro"` 是 zhishe-a2a 内部模型标识
- `max_tokens: 1500` 配合 V1.6 prompt 1456 字实测(V1.0/V1.1/V1.2/V1.3 同)
- `temperature: 0.7` 适合装修场景
