## 四、鸿蒙 HAP 端升级步骤(2 步,小艺审核通过后启动)

### 步骤 1:RenovationConsultAbility.ets 改 fetch 接收 stream

**当前代码**(V1.3):
```typescript
const res = await fetch("https://tunnel.zhishe.top/v1/chat/completions", {
  method: "POST",
  body: JSON.stringify({stream: false, ...})
})
const data = await res.json()
this.message = data.choices[0].message.content
```

**改成**(V1.4):
```typescript
const res = await fetch("https://tunnel.zhishe.top/v1/chat/completions", {
  method: "POST",
  body: JSON.stringify({stream: true, ...})
})
const reader = res.body.getReader()
const decoder = new TextDecoder()
let fullText = ""
while (true) {
  const {done, value} = await reader.read()
  if (done) break
  const chunk = decoder.decode(value)
  // 解析 SSE: data: {...}\n\n
  for (const line of chunk.split("\n")) {
    if (line.startsWith("data: ") && line !== "data: [DONE]") {
      const json = JSON.parse(line.slice(6))
      const delta = json.choices[0]?.delta?.content || ""
      fullText += delta
      this.message = fullText  // 实时刷新 UI
    }
  }
}
```
