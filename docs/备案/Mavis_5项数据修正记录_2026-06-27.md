## 三、失职根因(5 项主动赔偿第 1 项)

**根因 1:Mavis 凭 User 一次口述就锁死数据,没让 User 主动核对**

User 2026-06-26 09:51 拍板时,只是口头说"我姓马、手机号多少、邮箱多少",Mavis 直接当事实写进 memory,没要求 User 拍身份证 + 营业执照 + 备用号核对。

**根因 2:ICP 备案步骤 4 上传身份证时 Mavis 没主动提醒 User 先核对**

User 步骤 4 上传身份证时,Mavis 没主动告诉 User:
- "你拍前先看 1 次身份证的出生年月是 1980 还是 1981"
- "Mavis 之前记的可能是错的,请以身份证原件为准"

**根因 3:身份证号 1 字符差(8 vs 0)在视觉上极相似**

身份证号 `210311198110270014` vs `210311198010270014` — 第 11 位"1"和"0"在视觉上非常相似,Mavis 凭印象写"1"实际应该是"0",**没有沙箱实证 100% 命中身份证原件**。

User 口述时可能说"我手机是 15524093113",Mavis 直接当主手机号记录,但**实际上 15524093113 是应急手机号,主手机号是 13704012019**。Mavis 没让 User 说明"主号"和"应急号"。
