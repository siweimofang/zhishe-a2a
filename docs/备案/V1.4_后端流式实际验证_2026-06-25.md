## 五、鸿蒙 HAP 端 stream 接收代码 diff(可直接 apply)

**文件**:`D:\DevEcoProjects\zhishe_renovation_agent\entry\src\main\ets\entryability\RenovationConsultAbility.ets`

**改动**(V1.3 → V1.4):
```diff
-    const res = await fetch("https://tunnel.zhishe.top/v1/chat/completions", {
-      method: "POST",
-      body: JSON.stringify({stream: false, ...})
-    })
-    const data = await res.json()
-    this.message = data.choices[0].message.content
+    const res = await fetch("https://tunnel.zhishe.top/v1/chat/completions", {
+      method: "POST",
+      body: JSON.stringify({stream: true, ...})
+    })
+    const reader = res.body.getReader()
+    const decoder = new TextDecoder()
+    let fullText = ""
+    while (true) {
+      const {done, value} = await reader.read()
+      if (done) break
+      const chunk = decoder.decode(value)
+      for (const line of chunk.split("\n")) {
+        if (line.startsWith("data: ") && line !== "data: [DONE]") {
+          const json = JSON.parse(line.slice(6))
+          const delta = json.choices[0]?.delta?.content || ""
+          fullText += delta
+          this.message = fullText  // 实时刷新
+        }
+      }
+    }
```
