### 目标 2:让装修从"信息黑盒"变"信息透明"(2026-2030)

**为什么**:
- 装修行业 = 信息严重不对称
- 业主不懂 → 装修公司宰客
- 增项陷阱 / 偷工减料 / 阴阳合同 → 业主亏 30%

**Mavis 怎么解决**:
- **Phase 1 Wait!**(已实装) = 报价超 30% 偏离 → 触发护栏 → 拒绝回答
- **Phase 2 LLM-as-judge**(Mavis 计划) = 智能识别"陷阱式"问题 → 主动提示
- **5 个 Skill** = 5 大能力点 = 装修全流程知识体系
- **沈阳本地价格精准** = 多年老法师数据 = 跟"信息差"对抗
- **不替用户做决定** = 用户自主权 = 反"控制式"营销

**衡量指标**:
- 智能体帮助业主避坑率:从 0% → 30%(Mavis 自评)
- 装修业主平均节省费用:从 0 → 5-10 万/单(基于 Phase 1 Wait! 数据)
- 装修投诉率:从 18% → < 10%(假设 1 万用户)

### 目标 3:用技术降低"专业门槛"(2027-2030)

**为什么**:
- 装修设计 = 专业人士的事(月薪 1-2 万设计师)
- 普通业主 = 看不到方案 / 听不懂术语
- 智能体 = 把专业知识"翻译"成"业主能听懂的话"

**Mavis 怎么解决**:
- **多模态**:V3.0+ 接入图片(户型图 / 装修效果图)
- **语音输入**:V3.0+ 老人 / 打字不熟练的人用
- **VR 看房**:V4.0+ 戴 VR 头显"实地预览"装修效果
- **方言支持**:V2.5+ 沈阳话 / 北京话 / 川渝话

## 六、3 大风险(沙箱实证,长期)

### 风险 1:DeepSeek API 限流 / 涨价

**影响**:业务挂掉 / 成本上升
**应对**:
- 多 API Key 备份
- QPS 提升申请
- 备用模型(MiniMax-M3 / Qwen)
- 长期:模型微调本地化

### 风险 2:小艺 / 华为 / 国家政策变化

**影响**:上架被禁 / 备案重做
**应对**:
- 多端分散风险(5 大外壳)
- 政策监控(cron)
- 备案材料全备(4 份核心 + 1 份工作证明)
- 合规运营(不碰红线:不加微信 / 不逼单 / 不夸大)

### 风险 3:竞品出现(大厂 / 创业公司)

**影响**:市场份额被抢
**应对**:
- 行业 Know-how 护城河(老法师不可复制)
- 沈阳本地数据(其他城市难复制)
- 5 大 Skill 完整覆盖(创业公司难做齐)
- 长期用户沉淀(V2.0+)
