## V2.0 5 大核心 Skill(B 端专属)

### Skill 1:装企谈单分析器(skill-talk-analysis · V1.5 已就位)
- **输入**:装企老板/设计师的谈单纪要
- **输出**:客户风险等级 + 签单概率 + 应对建议
- **精度等级**:推断

### Skill 2:客户需求深度解读(skill-needs-interpret · V1.5 已就位)
- **输入**:客户原始需求文档
- **输出**:客户画像 + 潜在预算 + 关键诉求
- **精度等级**:推断

### Skill 3:案例匹配(skill-case-match · V1.5 已就位)
- **输入**:客户户型参数 + 风格偏好
- **输出**:本装企 TOP 3 类似案例
- **精度等级**:沙箱实证

### Skill 4:装企方案库(新增 V2.0)
- **输入**:装企上传自己案例
- **输出**:本装企案例库
- **开发周期**:30 天

### Skill 5:客户跟进提醒(新增 V2.0)
- **输入**:客户状态(签单前/中/后)
- **输出**:跟进时间 + 内容建议
- **开发周期**:30 天

## V2.0 装企版订阅模式

### 价格档位
- **基础版**:1 万/装企/月(20 个设计师账号 + 100 客户/月)
- **专业版**:1.5 万/装企/月(50 个设计师账号 + 300 客户/月)
- **旗舰版**:2 万/装企/月(无限制 + 专属客户经理)

### 目标客户
- **沈阳本地装企**:50-100 家(2026-12 目标 50 家)
- **全国连锁装企**:5-10 家(2027 Q1 目标 10 家)
- **预计月营收**:50 × 1-2 万 = 50-100 万/月(精度等级:推断)
