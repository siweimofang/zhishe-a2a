## 二、8 大异常预案(User 通知 Mavis 哪类,Mavis 立刻响应)

### 异常 1:小艺 APP 搜不到"知设装修顾问"

**用户感知**:
- 小艺 APP 搜索"知设装修顾问"→ 找不到

**Mavis 排查**:
1. 查小艺平台通知(可能审核中 / 被驳回)
2. 登录小艺开发者中心 → "我的智能体" → 看状态
3. 状态变成"已上架"但搜不到 → 缓存问题,等 24 小时

**应急**:
- User 走"反馈与建议"通道:小艺 APP → 我的 → 反馈与建议
- Mavis 重提智能体(走小艺审核通道)

### 异常 2:小艺回复内容违规(被警告)

**用户感知**:
- 智能体突然回复"加我微信 sxxxxx" / "8 年经验"
- 平台发警告

**Mavis 排查**:
1. 查 V1.7.2 prompt 有没有被改回去
2. 跑铁律 20 自检 → 看真违规数
3. 查最近部署历史 → 是不是有"未测试"的代码上线

**应急**:
- Mavis 重写 prompt → 部署 V1.7.3 → 走小艺"反馈与建议"通道
- 1-2 工作日审核

### 异常 3:V1.3 智能体 5 题答错(80% 不达标)

**用户感知**:
- 真用户测试 5 类问题,4-5 题答错

2. 查 V1.7.2 prompt 对应 Skill 段
3. 跑铁律 13 Phase 1 Wait! 自纠错 → 看 LLM 输出

**应急**:
- Mavis 改 prompt 4-5 处 → 部署 V1.7.3 → 重提
- 1-2 工作日

### 异常 4:主页 / health 502 / 503 / 504

**用户感知**:
- 小艺回复"系统繁忙,请稍后再试"
- tunnel.zhishe.top 主页打不开

**Mavis 排查**:
1. ssh 上服务器(等 User 给权限)
2. `ps aux | grep uvicorn` → 后端进程
3. `systemctl status nginx` → nginx 状态
4. `tail -f /var/log/nginx/error.log` → nginx 错误
5. `tail -f uvicorn.log` → Python 错误

**应急**:
- 后端挂了 → `restart_v14_v173.py` 重启
- nginx 挂了 → `systemctl restart nginx`
- 流量爆了 → Cloudflare 启用"5 秒盾"防 DDoS

### 异常 5:Cloudflare 5xx 错误(SSL / Tunnel)

**用户感知**:
- 主页间歇性 502 / 521 / 522 / 524
- 小艺返回 5xx

**Mavis 排查**:
1. `https://tunnel.zhishe.top/` → 实际状态码
2. Cloudflare Dashboard → tunnel.zhishe.top → 看 Analytics
3. Cloudflare 状态页:`https://www.cloudflarestatus.com/`

**应急**:
- Cloudflare Tunnel 挂了 → 备用 URL(待定)
- SSL 过期 → Cloudflare 自动续期,等 1 小时
- 大量流量 → 启用 Cloudflare Rate Limiting

### 异常 6:DeepSeek-v4-pro API 限额 / 挂掉

**用户感知**:
- 智能体突然 5xx 错误
- 后端日志"DeepSeek API timeout"

**Mavis 排查**:
1. DeepSeek 状态页:`https://status.deepseek.com/`
2. 后端日志看 timeout 数
3. 查 API Key 余额

**应急**:
- API 挂掉 → 切换备用 LLM(智谱 / 月之暗面)
- API 限额 → 升级套餐 / 等下个月
- Mavis 准备 fallback:`/v1/chat/completions` 接 2-3 个 LLM
