## 一、平台澄清(2026-06-26 沙箱实证)

### 重要:**V1.1 元宝 ≠ 腾讯元宝 App**
- **腾讯元宝 App**:C 端聊天 App(类似 ChatGPT),需要直接调用混元/DeepSeek
- **腾讯元器**(yuanqi.tencent.com):B 端智能体创作平台 — **V1.1 元宝实际接入这个**
- 元器创建的智能体,可以发布到腾讯元宝 App + 微信公众号 + 微信小程序 + 企业微信

### V1.1 元宝接元器的 2 条路径

| 路径 | 方式 | 适用 |
|---|---|---|
| **A. 纯 LLM 模式(简单)** | 写 system prompt + 配置自定义 Skills ZIP | V1.3 经验复用 |
| **B. API 接入模式(高阶)** | 元器调外部 HTTPS API(我们的 A2A 服务) | 完整流式 + 多 Skill 调度 |

**Mavis 推荐 A 路径(简单复用 V1.3 经验)**:
- 优点:工作量小,1-2 天配置完
- 缺点:不能复用 V1.3 的流式响应
- **Mavis 推**:V1.1 元宝 = A 路径,V1.2 豆包 = B 路径(差异化)

## 六、5 Skill 知识库文档(Mavis 提供)

### 6.1 renovation_quote(装修报价)

```
# 装修报价 Skill

## 适用场景
用户问装修价格相关问题,如:
- 我家 90 平三室,想半包,大概多少钱?
- 全包和半包有什么区别?
- 100 平基础装修要多少钱?

## 报价公式
- 半包(基础硬装):500-800 元/平
- 全包(主材+辅材+施工):1000-2000 元/平
- 全案(设计+施工+主材+软装):2000-5000 元/平

## 5 大分项
1. 设计费(3-5%):方案 + 施工图
2. 拆改(5-10%):拆墙/砌墙/换门窗
3. 水电(15-20%):水管/电线/防水
4. 泥木(20-30%):瓷砖/地板/吊顶
5. 油漆(10-15%):墙面/顶面

## 免责说明
- 上述价格为行业参考区间,具体以本地实际为准
- 建议至少 3 家装修公司对比报价
- 警惕"低价切入,后期增项"
```

### 6.2 construction_standard(施工标准)
```
# 施工标准 Skill

## 适用场景
- 水电改造要注意什么?
- 防水做多高?
- 墙面怎么验收?

## 5 大施工标准
1. 水电改造:横平竖直、强弱电分管、间距 30cm
2. 防水:卫生间淋浴区 1.8m,其他区域 0.3m,闭水试验 48h
3. 墙面:石膏找平 + 腻子 2 遍 + 底漆 + 面漆
4. 地面:水泥砂浆找平,平整度 ≤ 3mm
5. 木作:轻钢龙骨 + 防火涂料 + 防潮处理

## 验收规范
- 隐蔽工程必须拍照存档
- 每道工序验收合格再进入下道
- 合同约定验收标准(GB 50210 / GB 50242)
```

### 6.3 design_scheme(设计方案)
```
# 设计方案 Skill

## 适用场景
- 小户型怎么设计显大?
- 90 平三室两厅怎么布局?
- 日式风格和北欧风格有什么区别?

## 5 大设计维度
1. 户型改造:承重墙不能拆,非承重墙可优化动线
2. 空间布局:动静分区,公私分区,干湿分区
3. 风格搭配:现代/北欧/日式/美式/新中式
4. 动线设计:家务动线 / 居住动线 / 访客动线
5. 收纳规划:玄关/客厅/卧室/厨房 4 大收纳区

## 设计原则
- 实用性 > 美观性
- 收纳占套内面积 12-15%
- 插座数量 = 户型面积 × 0.5
```

### 6.4 building_material_brand(建材品牌)
```
# 建材品牌 Skill

## 适用场景
- 乳胶漆什么牌子好?
- 地板哪个品牌性价比高?
- 卫浴选什么品牌?

## 4 大类品牌推荐
1. 主材(地板/瓷砖/卫浴):
 - 高端:马可波罗/诺贝尔/TOTO/科勒
 - 中端:东鹏/欧神诺/箭牌/九牧
 - 性价比:蒙娜丽莎/萨米特/惠达/恒洁

2. 辅材(电线/水管/水泥):
 - 电线:远东/熊猫/上上
 - 水管:伟星/中财/金牛
 - 水泥:海螺/冀东/华新

3. 家具(床/沙发/柜子):
 - 实木:南洋胡氏/华日/曲美
 - 定制:欧派/索菲亚/志邦

4. 家电(空调/冰箱/洗衣机):
 - 美的/格力/海尔/西门子

## 选购建议
- 大件家电 618 / 双 11 入手(便宜 20-30%)
- 建材团购前先看样品
- 品牌不是唯一,售后更重要
```

### 6.5 renovation_pitfall(避坑指南)
```
# 装修避坑指南 Skill

## 适用场景
- 装修最容易踩的坑是什么?
- 合同要注意什么?
- 怎么防止增项?

## 10 大常见陷阱
1. 低报价切入:报价 8 万,实际 12 万
2. 增项:水电按实结算,远超预算
3. 偷工减料:电线换小一号,水管换杂牌
4. 拖延工期:合同 90 天,实际 150 天
5. 主材以次充好:样品和大货不一致
6. 隐蔽工程不拍照:漏水后扯皮
7. 付款节点不合理:开工 60% → 风险大
8. 工人手艺差:瓷砖空鼓,墙面开裂
9. 环保不达标:甲醛超标,白血病风险
10. 售后无保障:装修公司跑路

## 6 大合同要点
1. 报价清单:材料品牌/型号/数量/单价
2. 工期:明确开工日和完工日,逾期违约金
3. 付款:3331 比例(开工 30%,水电 30%,泥木 30%,竣工 10%)
4. 增项:单项 ≤ 5% 总价
5. 主材:样品封存,大货对比
6. 售后:2 年质保,终身维护(水电)

## 避坑原则
- 不找"价格最低"
- 不签"闭口合同"
- 不付"高比例预付款"
- 一定"分阶段验收"
```
