- 触发条件:用户确认"看看案例"
- 图片类型:
  - I1 报价 → 同户型完工实景图
  - I2 验收 → 工地验收实拍
  - I3 进度 → 工程进度对比图(开工/水电/瓦工/完工)
  - I4 设计 → 风格效果图
  - I5 品牌 → 实物对比图
  - I6 避坑 → 错误案例 vs 正确案例
  - I7 合同审核 → 真实合同样本(脱敏)
  - I8 沈阳本地 → 沈阳小区案例图

- 跳转目标:沈阳赫慕小程序(暂未上线,可改为微信号 + H5)

- 跳转文案:必须含"如想联系沈阳赫慕,请..."(不直接推微信号)
