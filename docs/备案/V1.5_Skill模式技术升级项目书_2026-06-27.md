## 三、V1.5 Skill 模式核心技术要求(沙箱实证:华为官方)

### 3.1 文件结构(必须)

```plaintext
skill-name/
├── SKILL.md        # 元数据 + 指令(面向 Agent)
├── module.json     # 平台配置(面向运行时框架)← 新增
├── scripts/        # 可选:脚本文件
├── references/     # 可选:参考文档
└── assets/         # 可选:静态资源
```

### 3.2 SKILL.md 鸿蒙规范

| 字段 | 要求 | 沙箱实证 |
|---|---|---|
| **description** | ≤512 字符,含能力概括 + 适用情形 + 不适用情形 | 华为官方 Skill V6 |
| **触发关键词** | 系统从 description 自动提取,不需要手写 | 华为官方 |
| **正文** | ≤500 行,建议 ≤5000 tokens | 华为官方 |
| **结构** | 知识层 → 能力层 → 编排层 → 协作层(4 层) | 华为官方 |
| **工具数** | 5-20 个工具/Skill | 华为官方 |
| **安全** | 静态规则扫描(必须)+ LLM 语义审计(建议) | 华为官方 |

### 3.3 module.json 核心要求(沙箱实证)

```json
{
  "name": "skill-quote",
  "version": "1.0.0",
  "availableOn": ["phone", "tablet", "2in1"],
  "toolDependencies": [
    "renovation-quote-api",
    "city-pricing-data"
  ],
  "entry": "SKILL.md",
  "schema": "v6",
  "permissions": [
    "network",
    "read-city-pricing"
  ]
}
```
