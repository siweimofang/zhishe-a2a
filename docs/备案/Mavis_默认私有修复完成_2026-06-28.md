## 2. 修复方案(Mavis 干)

### 2.1 新增 `app/api/auth.py`(统一鉴权依赖)

```python
async def require_api_key(authorization: Optional[str] = Header(default=None)):
    if not _verify_api_key(authorization):
        raise HTTPException(status_code=401, detail="Invalid API key")
    return authorization
```

**特性**:
- 未配 `A2A_API_KEY`:本地联调放行(返回 True,防止本地开发炸)
- 已配 `A2A_API_KEY`:必 Bearer 鉴权通过
- 错误:返回 401 + `{"detail": "Invalid API key"}`(与 OpenAI 标准一致)

### 2.2 修改 `app/main.py`
