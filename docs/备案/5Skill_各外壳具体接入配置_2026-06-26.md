## 二、V1.0 千问(已发布):5 Skill 配置

### 配置方式
V1.0 千问版**不显式注册 Skill** — 千问是"自定义模型导入"模式,只能配"系统提示词 + 模型名"。

### 千问版实际配置
- **模型名**:deepseek-v4-pro
- **系统提示词**:V1.7.2 prompt 全量嵌入(由 Mavis 在百炼后端配)
- **5 Skill**:**通过系统提示词内的"角色指令"实现**,不是显式 Skill 注册

### 千问版 5 Skill 触发方式
用户在千问 APP 里问装修问题 → 千问转发到 zhishe-a2a 后端 → 后端根据 V1.7.2 prompt 自动判断属于哪个 Skill → 给出对应回答。

### 验证步骤
1. 打开千问 APP
2. @知设装修顾问(或直接问装修问题)
3. 输入装修问题,看回答质量

 - 施工类(对应 construction_standard)

## 七、5 Skill 接入统一原则(Mavis 决策)

### 8 个不变原则(无论哪个外壳)
1. **id / name / description / tags / examples 字段一致**(从 AgentCard 直接复制)
2. **5 个 Skill 都接**(不删不减)
3. **中英文双语 tags**(装修 / renovation 等)
4. **每个 Skill 3 个 examples**(统一标准)
5. **头像 / 主页 / 隐私 / 协议 4 个 URL 复用**(永久地址)
6. **V1.7.2 prompt 全量嵌入**(不变)
7. **不加微信 / 不逼单**(小艺平台红线 + User 铁律)
8. **只服务中国境内**(铁律 15)

### 6 个可变项(每个外壳差异)
1. **接入协议**(OpenAI 兼容 / A2A 0.2.5)
2. **端点 URL**(同后端,不同路径)
3. **API Key 鉴权方式**(Bearer / X-API-Key)
4. **流式支持**(V1.3+ 用 streaming=True,V1.0 用非流式)
5. **平台审核周期**(1-3 工作日)
6. **平台特定字段**(智谱有 GLM 模型选项 / 小艺有鸿蒙设备)
