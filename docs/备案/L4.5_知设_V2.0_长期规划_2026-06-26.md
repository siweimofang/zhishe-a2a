## 二、V2.0+ 阶段定义(2026-07 ~ 2027-12)

### V2.0 起点定义
- V1.x 阶段(2026-06 ~ 2026-09)= **C 端单设备**(手机 + 平板 + 2in1 装修 AI)
- V2.0 阶段(2026-10 ~ 2027-06)= **C + B 端 + 多模态 + AI 设计**
- V2.5 阶段(2027-07 ~ 2027-12)= **装企版 + 订阅 + 数据沉淀**

### V2.0 三大核心变化
1. **从"问答"到"执行"**:智能体不止回答,还能接入图片 / 出图 / 报价单生成
2. **从"个人"到"装企"**:B 端订阅模式,装修公司付费,业主免费
3. **从"全国"到"全球中文市场"**:港澳台 / 海外华人(注意:不接外国用户,只接中文市场)

### Mavis 主动建议
- **C 端永久免费**(获客漏斗)

- **不收个人年费**(避免用户抵触 + 简化运营)
