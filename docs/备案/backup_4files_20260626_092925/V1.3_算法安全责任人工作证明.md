## 二、岗位职责

马庄南同志作为本单位的法定代表人,同时担任本单位互联网信息服务算法的**算法安全责任人**,具体岗位职责如下:

### (一)组织协调职责
1. 统筹本单位算法安全工作的实施,确保装修类生成式 AI 服务的安全性和稳定性
2. 负责与监管部门、网信办、辽宁省网信办等相关部门进行沟通协调
3. 监督和评估算法安全措施的执行效果,及时修正和改进
4. 提报算法安全工作的情况和问题,向上级主管部门汇报

### (二)制度建设职责
1. 建立健全本单位算法安全管理制度体系(9 大制度)
 - 算法安全管理制度
 - 算法自评估制度
 - 算法监测制度
 - 算法应急处置制度
 - 算法违法违规处置制度
 - 个人信息保护制度
 - 网络与信息安全管理
 - 信息系统安全保密制度
 - 信息安全风险应急预案
2. 制定本单位算法安全相关规范和政策

### (三)技术保障职责
1. 引入安全技术体系(网络安全技术、数据加密技术等)
2. 建立完善的访问控制机制,对算法系统进行权限管理和访问审计
3. 定期进行安全漏洞扫描和风险评估,及时修复和防范安全漏洞
4. 加强算法系统的日志记录和分析,发现异常行为并做出相应处理

### (四)应急处置职责
1. 负责对算法安全事件进行评估、处置和恢复
2. 启动应急预案时担任总指挥,统一调度相关部门
3. 协调与监管部门、用户、媒体等各方的沟通

### (五)用户权益保护职责
1. 监督用户隐私政策、用户协议的执行
2. 受理用户申诉和建议,保护用户合法权益
3. 确保用户知情权、选择权、申诉权
