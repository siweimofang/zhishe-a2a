## 二、算法基本原理

本算法是一种基于生成式预训练变换器(GPT)架构的智能对话算法,通过调用 DeepSeek-v4-pro 第三方已备案大模型 API,实现面向装修行业的对话式咨询服务。

**核心组件**:
1. **大模型基座**:调用 DeepSeek-v4-pro 大语言模型(已通过国家网信办大模型备案)
2. **领域封装**:结合装修行业专业知识库(报价库/标准库/建材库),实现行业垂直应用
3. **意图识别**:通过小型分类模型识别用户需求(报价/标准/建材/品牌)
4. **检索增强生成(RAG)**:基于知识库检索 + 大模型生成,提升答案准确性与专业性
5. **内容审核**:通过关键词过滤 + 深度学习分类,确保输出内容合规
6. **结果标识**:为生成内容添加"AI 生成"显式标识 + 隐式元数据

## 三、算法运行机制

### (一)整体运行流程

```
[用户输入] → [意图识别] → [知识库检索] → [DeepSeek API 调用]
   ↓
[结果标识] → [内容审核] → [返回用户]
```

### (二)详细步骤

| 步骤 | 描述 |
|---|---|
| 1. 用户输入 | 用户在小艺智能体、千问 APP、微信公众号等渠道发起装修咨询 |
| 2. 请求预处理 | 清洗用户输入,识别意图(报价/标准/建材/品牌) |
| 3. 意图识别 | 基于小型分类模型识别用户需求类型 |
| 4. 能力分发 | 根据意图路由到对应的专业能力模块 |
| 5. 知识库检索 | 每个模块对应一个专业装修知识库(RAG) |
| 6. 大模型调用 | 结合知识库检索结果,调用 DeepSeek-v4-pro API 生成专业回答 |
| 7. 结果标识 | 为生成内容添加"AI 生成"显式标识 + 隐式元数据 |
| 8. 内容审核 | 通过关键词过滤 + 深度学习分类过滤违规信息 |
| 9. 返回用户 | 最终回答返回给用户 |

### (三)输入输出

**输入数据类型**:文本(简体中文)

**输出数据类型**:文本(简体中文)

**输入数据格式**:自然语言问询(最长 2000 字符)

**输出数据格式**:结构化文本(最长 3000 字)

## 四、算法应用场景

- **场景 1**:装修报价咨询(基础预算、详细报价、不同档次对比)
- **场景 2**:施工标准问答(国标/地标/工艺标准/验收标准)
- **场景 3**:设计方案咨询(风格/布局/色彩/采光)
- **场景 4**:本地化建材推荐(沈阳/全国 7 大品牌建材市场)
- **场景 5**:装修避坑指南(常见装修陷阱/虚假宣传识别)

**目标用户**:有装修需求的 C 端用户(主要 25-55 岁)

## 五、算法目的意图

**核心目的**:为有装修需求的 C 端用户提供专业、及时、免费的装修咨询服务,降低装修知识门槛,帮助用户做出更明智的装修决策。

**核心价值**:8 年装修行业经验 + AI 技术 = 专业、及时、可靠的装修顾问

**服务对象**:面向公众(To C)有装修需求的用户

## 六、安全措施

### (一)内容安全

- 关键词过滤:覆盖政治、色情、暴力、虚假信息等 10000+ 关键词
- 深度学习审核:对疑似违规内容进行二次审核
- 人工抽检:每日抽检 100+ 算法输出内容

### (二)数据安全

- HTTPS/TLS 1.3 加密传输
- API Key 安全存储(环境变量)
- 用户对话数据不留存

### (三)模型安全保障

- 仅调用已备案的第三方大模型(DeepSeek)
- 模型版本管理 + 回滚机制
- A/B 测试 + 灰度发布

### (四)用户权益保护

- 显式标识"AI 生成"
- 不留存用户数据
- 提供投诉举报渠道

## 七、用户干预机制

### (一)关闭个性化推荐

本算法不涉及个性化推荐,所有用户得到相同的装修知识服务。

### (二)投诉举报渠道

用户在对话中可指出错误信息,或在产品设置中找到"反馈与建议"入口提交投诉。

- **选择权**:用户可拒绝使用本服务
- **反馈权**:用户可随时反馈意见
