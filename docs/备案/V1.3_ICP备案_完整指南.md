    "icp": "辽ICP备XXXX号-1",
    "police": "辽公网安备 XXXXX 号"

@app.middleware("http")
async def add_compliance_headers(request, call_next):
    response = await call_next(request)

    return response

## 五、注意事项(高频踩坑)

### ⚠️ 踩坑 1:**域名持有者 = 备案主体**

如果 zhishe.top 在阿里云注册时用了**个人**实名,公司备案会**驳回**。

**解决**:检查域名 WHOIS,确认持有人 = "沈阳赫慕空间设计有限责任公司"

### ⚠️ 踩坑 2:**短信核验必须 24 小时内**

错过 = 自动退回 = 重来 1-2 周

### ⚠️ 踩坑 3:**网站负责人 ≠ 法人**

如果网站负责人用员工,需要额外上传**授权书**(盖章)

**简化方案**:网站负责人 = 法人 = 马壮男(无需授权书)

### ⚠️ 踩坑 4:**云服务必须有公网 IP**

阿里云 ECS 默认有公网 IP,99 元/年档位即可。

### ⚠️ 踩坑 5:**Cloudflare Tunnel 域名能否备案?**

**能**,但域名需要完成中国大陆**实名认证**(在 Cloudflare 后台)。

具体步骤:
1. 登录 Cloudflare 控制台
2. 域名管理 → zhishe.top → 注册商设置
3. 添加中国实名信息(法人/公司)
