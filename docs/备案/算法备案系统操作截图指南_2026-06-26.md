## 三、4 份材料 .md 转 PDF 精确流程

### 方案 1:Word / WPS(推荐)

1. 打开 Word / WPS
2. 文件 → 打开 → 选择 .md 文件
3. 提示"文本编码" → 选"UTF-8"
4. 另存为 → PDF
5. 命名规则:
 - `01_承诺书.pdf`
 - `02_主体责任.pdf`
 - `03_自评估报告.pdf`
 - `04_工作证明.pdf`

### 方案 2:VS Code 插件

1. 装插件"Markdown PDF"
2. 右键 .md 文件 → "Markdown PDF: Export (pdf)"
3. 4 份自动转 PDF

### 方案 3:在线转换

1. `https://www.markdowntopdf.com/`
2. 上传 .md 文件
3. 下载 PDF
4. 一次性最多 5 个文件

**Mavis 推方案 1**:最稳,文件大小可控,无水印。

## 四、5 大常见驳回原因(Mavis 提前预警)

### 驳回 1:ICP 备案未做
- 100% 驳回原因(算法备案系统必查)
- **必须先做 ICP 备案**(参见 A1 指南)
- ICP 备案号下来后再做算法备案

### 驳回 2:大模型备案号缺失
- 100% 必填字段
- DeepSeek 官方备案号由 DeepSeek 自己申请,不归 User 管
- **临时方案**:在"大模型备案号"字段填"待补充",系统可能让过

### 驳回 3:4 份材料不完整
- 9 大制度必全
- 工作证明必盖章 + 法人签字
- 自评估报告必 6 大模块

### 驳回 4:公示内容不清晰
- "应用领域"要简明("装修咨询" ✅, 智能问答 ✅)
- "是否收集个人信息"要明确

### 驳回 5:经营范围不匹配
- 营业执照有"建筑装饰工程设计、施工"才能做
- 沈阳赫慕有 ✅
