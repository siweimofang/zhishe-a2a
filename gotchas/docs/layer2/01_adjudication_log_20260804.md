## 一、裁决规则

验证器主张与标准事实冲突时，按以下规则裁决：

1. 验证器主张有标准原文/权威依据支撑 → 采纳，条目须修正
2. 验证器主张属幻觉（标准名称错误、效力状态臆断、数值张冠李戴）且无依据 → 驳回
3. 验证器主张指向条目表述不严谨但无事实错误 → 降级为改进建议（improvement），不阻断入库
4. 双方均有部分道理 → 采纳合理部分修正，驳回其余
