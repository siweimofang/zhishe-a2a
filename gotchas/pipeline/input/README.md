# 素材投喂说明

把要入库的装修经验写成纯文本文件，放在本目录（`gotchas/pipeline/input/`）。

## 格式约定

- 一个文件可含多条经验，**多条之间用单独一行 `---` 分隔**。
- 没有 `---` 时，整个文件按一条素材处理（AI 会自动拆分其中的多个坑点）。
- 每条经验尽量写清：是什么坑、为什么坑、大概损失、怎么避免。
- 过短的片段（少于 20 字）会被自动跳过。

## 示例

```
瓦工铺瓷砖最怕空鼓。水泥砂浆配比不对、基层没拉毛，砖和墙之间就会形成空腔，
敲上去咚咚响。空鼓率超过国标 5% 必须返工，不然砖后期会脱落砸伤人。
验收一定要用空鼓锤逐块敲。
---
大板瓷砖上墙不能用水泥砂浆，必须用瓷砖胶薄贴法。很多工人图省事还是用水泥，
半年后大板整块脱落，损失上万。
```

## 运行

```
cd gotchas/pipeline
python run_annotate.py --input input/瓦工瓷砖.txt --dry-run   # 先试运行看效果
python run_annotate.py --input input/瓦工瓷砖.txt             # 正式产出到待审区
python run_review.py                                          # 逐条审核入库
```
