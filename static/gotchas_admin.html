回滚与卸载

回滚最新一条：撤销栈顶副作用（LIFO）。全量回滚：逆序撤销全部业务副作用，系统级钩子自动保留。
按 ID 回滚会连同其上方的副作用一并回滚（LIFO 语义）；目标上方的依赖可能挂在它身上。
R1：进入只读态，拒绝一切新副作用；R2：带守卫回滚全部已施加副作用后恢复受理；取消仅限 R1 阶段。
从 all_ku.json 全量重载并重建索引；未落盘的副作用会被覆盖，请先确认栈为空或已固化。

临时规则管理 (P3 创造模式)

创建临时规则：不写磁盘，重启/reload 即失。持久化：排除临时规则写入 all_ku.json（含 include_temp=true 可选）。
注册临时钩子：运行时生效，可精确回滚注销（上限 10 个）。
通过 batch_id 精确回滚某个临时批次的全部规则。
