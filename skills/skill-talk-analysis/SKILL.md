# 谈单分析 Skill

## 知识层

### 客户行为信号
- 价格敏感:"太贵了""有没有便宜的""再考虑下"
- 竞品对比:"别家说……""我再去 X 家问问"
- 犹豫:"我想想""回去商量下""下周给你答复"
- 决策权:"这个我做不了主""要跟老公/老婆商量"

### 风险等级
- 高风险:客户要"回去商量" + 提到竞品
- 中风险:客户要"再考虑" + 提到预算
- 低风险:客户主动问细节 + 询问施工

### 数据精度等级
- 风险预测模型:精度等级:推断
- 历史案例:精度等级:沙箱实证(8 个 Skill 已就位)

## 能力层(1 个工具)

### 工具 1:`scripts/risk_predict.py`(8467 字节)
- **功能**:基于客户对话内容,预测签单概率 + 风险等级
- **输入**:客户对话文本(谈单纪要)
- **输出**:风险等级(高/中/低)+ 应对建议
- **gotcha**:对话样本 < 3 句时预测准确率下降

## 编排层

### 触发场景
- 设计师:"客户刚才说太贵了,我该怎么跟进?"
- 装企老板:"客户提到别家更便宜,我该怎么回应?"
- 设计师:"客户说要回去商量,我还有机会吗?"

### 输入
- 客户对话文本 / 谈单纪要

### 输出
- 风险等级(高/中/低)
- 应对建议(3-5 条)
- 下一步行动(立即/1 天/1 周)

### Gotchas(2 条)
- 客户话术长度 < 3 句 = 预测不准,需主动引导设计师补充
- 客户提到"回去商量" = 立即补救,不能等
