# 案例匹配 Skill

## 知识层

### 案例库字段
- 城市 / 区域 / 面积 / 户型 / 风格 / 预算 / 实景图 / 装修时间

### 匹配算法
- 相似度 = 城市权重(0.3) + 户型权重(0.3) + 风格权重(0.2) + 面积权重(0.2)
- 阈值:相似度 > 0.7 = 强匹配,0.5-0.7 = 中匹配,< 0.5 = 弱匹配

### 数据精度等级
- 案例库:精度等级:沙箱实证
- 匹配算法:精度等级:推断

## 能力层(1 个工具)

### 工具 1:`scripts/case_match.py`(9174 字节)
- **功能**:基于用户参数匹配本地案例
- **输入**:户型 JSON + 风格偏好
- **输出**:TOP 3 案例 + 相似度评分
- **gotcha**:案例库 < 10 条时匹配质量下降
