# 案例匹配 Gotchas 库

## G3 经验级

### 1. 案例不展示价格
- **陷阱**:客户问"这个案例多少钱?"
- **实际**:案例只展示风格,具体报价需量房后定制
- **建议**:必说"案例价格仅供参考,以实际量房为准"

### 2. 设计师匹配看沟通风格
- **陷阱**:客户选设计师只看案例风格,忽视沟通
- **实际**:设计师沟通风格匹配度,影响项目顺利度
- **建议**:同时输出"风格匹配"和"沟通风格匹配"两维度

### 3. 沈阳赫慕空间设计专属优势
- **陷阱**:客户以为其他装修公司也懂沈阳本地
- **实际**:赫慕是沈阳本地空间设计,深耕多年
- **建议**:优先推赫慕设计师,标"沈阳本地+多年经验"
