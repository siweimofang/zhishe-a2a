## 三、Skill 能力(必含 4 个工具)

### 工具 1:成本核算 `scripts/cost_calc.py`(待写)
- **功能**:输入项目参数 → 输出总成本 + 利润 + 利润率
- **输入**:项目面积 + 城市 + 档次 + 装修方式 + 工种系数
- **输出**:工人成本 + 材料成本 + 管理成本 + 总成本 + 利润 + 利润率

### 工具 2:工人日工/月工单价查询 `scripts/worker_rate.py`(待写)
- **功能**:查询某工种在某城市的日工/月工单价
- **输入**:工种 + 城市 + 级别(学徒/熟练/老师傅)
- **输出**:日工单价 + 月工单价 + 数据来源 + 数据时间

### 工具 3:项目预算分解 `scripts/project_budget.py`(待写)
- **功能**:把项目预算分解到工种 + 工期
- **输入**:项目面积 + 装修方式 + 工期 + 工种系数
- **输出**:各工种工期 + 工人数量 + 工资总额

### 工具 4:利润率反算 `scripts/profit_calc.py`(待写)
- **功能**:反算装企 V2.0 OBP 定价的利润率
- **输入**:装企期望利润率 + 项目类型
- **输出**:建议 OBP 收费比例 + 基础订阅价格

## 五、Skill 与 skill-quote 联动

```
skill-quote(B→C 客户报价)
    ↓ 调用
skill-worker-cost(装企内部成本)
    ↓ 反算
装企 V2.0 OBP 定价(订阅+按结果付费)
```

**关键**:**skill-quote 不能调用 skill-worker-cost**(因为 skill-quote 是给客户的报价,不能透露成本)。但 **V2.0 装企版**可以两个都看,算"公司到底赚多少"。
