# 布局规划 Skill

## 知识层

### 布局方案标准
- 2-3 套方案(每套含:墙体改动 / 家具摆放 / 动线分析)
- 方案评分:空间利用率 / 采光 / 动线 3 维度

### 物理约束
- 承重墙:不可拆
- 卫生间/厨房:不可移到承重墙
- 燃气管道:改动需标注
- 楼板荷载:300 kg/m²

### 行业规则
- 卫生间:防水层 1.8 米
- 厨房:燃气管道改动需燃气公司审批
- 阳台:不可放置重物(承重限制)

### 数据精度等级
- 国标:精度等级:沙箱实证
- 行业规则:精度等级:沙箱实证

## 能力层(2 个工具)

### 工具 1:`scripts/constraint_check.py`(4293 字节)
- **功能**:物理约束 + 行业规则检查
- **输入**:布局方案 + 户型 JSON
- **输出**:约束违规列表(承重墙/管道/国标)
- **gotcha**:承重墙强制拦截(hook-bearing-wall,Phase 2)

### 工具 2:布局评分
- **功能**:方案评分(空间利用率 / 采光 / 动线 3 维度)
- **输入**:布局方案
- **输出**:3 维度评分(0-10)
