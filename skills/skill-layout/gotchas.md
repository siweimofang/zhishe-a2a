# 布局规划 Gotchas 库

## G1 致命级(必须 Hook 拦截)

### 1. 承重墙不能拆
- **陷阱**:客户想打通客厅和阳台,但阳台垛子是承重结构
- **实际**:承重墙拆除会导致整栋楼结构性破坏
- **G1 升级**:必须 Hook 强制拦截
- **Hook**:hook-bearing-wall(方案含拆承重墙 → 强制拒绝)

## G2 重要级

### 2. 卫生间沉箱不能改位置
- **陷阱**:客户想把卫生间从这头挪到那头
- **实际**:沉箱管道位置已定,改位置需要重新做防水 + 抬高地面
- **建议**:必须在原始位置范围内调整

### 3. 厨房燃气管不能包死
- **陷阱**:客户想做开放式厨房,把燃气管包进柜子里
- **实际**:燃气公司要求燃气管外露,便于检修
- **建议**:橱柜预留检修口

### 4. 卧室门不能对着卫生间门
- **陷阱**:小户型常出现卧室门正对卫生间门
- **实际**:风水忌讳 + 异味问题
- **建议**:做 L 型墙或加屏风

## G3 经验级

### 5. 沙发靠墙是误区
- **陷阱**:客户认为沙发一定要靠墙
- **实际**:沙发不靠墙反而能扩大客厅视觉
- **建议**:大户型建议沙发后留 1 米走道

### 6. 餐桌周围至少留 90cm
- **陷阱**:餐桌离墙太近,坐下后挤
- **实际**:椅子拉出后需要 70cm,加 20cm 走道 = 90cm
- **建议**:餐桌周围留 90cm 以上
