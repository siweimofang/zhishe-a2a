## G3 经验级(普通区,Phase 0 初始 5 条)

### 1. 沈阳地暖报价不含分水器
- **陷阱**:客户拿到"地暖 XX 元/㎡"报价,以为包含所有配件
- **实际**:地暖报价通常不含分水器,需单独计算(约 200-400 元/组)
- **来源**:沈阳赫慕空间设计多年实测(2026-06-26 录入)
- **建议报价模板**:地暖必须分项,分水器单独列出

### 2. 乳胶漆面积不含底漆
- **陷阱**:报价单上写"乳胶漆 XX 元/㎡",客户以为含底漆 + 面漆
- **实际**:底漆按 1 遍、面漆按 2 遍,底漆通常单独计费或注明"另算"
- **建议报价模板**:底漆 + 面漆必须分开列,或注明"含 N 遍底漆 + N 遍面漆"

### 3. "全包"在沈阳市场的定义
- **陷阱**:客户以为"全包 = 拎包入住"
- **实际**:沈阳"全包"通常指硬装 + 主材(瓷砖/地板/橱柜/卫浴/门),不含家电 + 软装 + 家具
- **建议报价模板**:全包清单必须明确"含 / 不含"项,让客户签合同前看清楚

### 4. 89 平三室两厅的卫生间数量
- **陷阱**:客户期望 89 平能有 2 个卫生间(主卧 + 次卧)
- **实际**:89 平三室通常只有 1 个卫生间(主卧不带卫生间)
- **建议报价模板**:报价前必问"几个卫生间",避免后期增项

### 5. 阳台封窗不属于硬装
- **陷阱**:客户以为阳台封窗包含在硬装内
- **实际**:阳台封窗通常属于业主自购项目(找专业封窗公司做)
- **建议报价模板**:硬装清单明确"不含阳台封窗",或单独报价

## 升级机制

- **G3 → G2**:同一条 Gotcha 出现 3 次以上,升级为重要,写入高优区
- **G2 → G1**:出现 5 次以上 / 违反导致严重错误,升级为 Hook 确定性拦截
- **G1**:进入 `app/services/hooks.py`,模型决策前 / 后强制检查
