## 能力层(4 个工具)

### 工具 1:`scripts/price_check.py`(5377 字节)
- **功能**:报价结果与 city_pricing.json 基准对比,标出偏差
- **输入**:报价 JSON + 城市 + 区域
- **输出**:偏差值(%)+ 风险等级(低/中/高)
- **gotcha**:偏差 > 30% 需预警

### 工具 2:`scripts/area_calc.py`(9329 字节)
- **功能**:墙面/地面/顶面面积计算(含门窗扣减)
- **输入**:户型 JSON(rooms 数组)
- **输出**:墙面/地面/顶面 3 个面积 + 门窗扣减明细
- **gotcha**:层高 > 3 米需特殊处理

### 工具 3:`scripts/price_calc.py`(8243 字节)
- **功能**:分项报价计算(硬装 + 主材 + 人工)
- **输入**:面积 + 城市 + 档次 + 装修方式
- **输出**:5 大项分项 + 总价区间
- **gotcha**:材料费占比应在 30-40% 区间

### 输入参数
| 参数 | 类型 | 必填 | 示例 |
|---|---|---|---|
| city | string | 是 | 沈阳 |
| district | string | 是 | 浑南 |
| total_area | number | 是 | 89 |
| room_count | string | 否 | 3室1厅 |
| tier | enum | 是 | 经济型/中档/中高档/豪华 |
| package_type | enum | 是 | 半包/大包/全案 |

### 输出格式
```yaml
分项报价:
  硬装: ¥XX,XXX
  主材: ¥XX,XXX
  人工: ¥XX,XXX
  辅材: ¥X,XXX
  其他: ¥X,XXX
总价区间: ¥XXX,XXX - ¥XXX,XXX(中位 ¥XXX,XXX)
风险提示: |
  ⚠️ 总价偏差 18%(>15% 阈值)
  ⚠️ 材料费占比 35%(在 30-40% 区间)
数据来源: 13 城 52 区基准价(2026-06-26)
免责声明: |
  以上报价为市场参考价,实际价格以实地量房 + 业主预算为准。
  本智能体不提供具体承诺价,建议实地量房 + 多家对比。
```

### Gotchas(5 条)
- 必须使用 city_pricing.json 的区域基准价
- 材料费占比应在 30-40% 区间
- 总价不得超过业主预算的 120%
- 必须分项列出硬装/主材/人工
- 必须输出数据来源(国标/官网/行约/待核实)
